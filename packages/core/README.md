# @eleven-am/golem-core

Framework-free core of [Golem](https://github.com/eleven-am/golem): the datamodel contracts, the operation engine, the policy kernel (constraints, transactional write verification, field permissions, read masking), the schema builder and the event machinery.

You normally install this alongside `@eleven-am/golem` rather than using it directly. See the [root README](https://github.com/eleven-am/golem#readme).
