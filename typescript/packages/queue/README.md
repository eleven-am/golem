# @eleven-am/golem-queue

Durable NestJS jobs with Prisma persistence, leases, retries and cancellation.

```sh
npm install @eleven-am/golem-queue
```

Apply the package schema and provider migration before registering workers. The guide covers typed handlers, resource pools, ordering and custom stores.
