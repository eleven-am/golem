# @eleven-am/golem-core

Framework-free engine and schema contracts for the Prisma/NestJS backend.

```sh
npm install @eleven-am/golem @eleven-am/golem-core
```

Install alongside the NestJS module. The guide covers the required upsert guard, provider support, event bounds and public contracts.
