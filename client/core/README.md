# @eleven-am/golem-client

TypeScript client for the Go backend: typed GraphQL requests, live queries and session-safe recovery.

```sh
npm install @eleven-am/golem-client @tanstack/query-core graphql graphql-ws
```

Use the manifest generated by the Go CLI. Await `client.ready()` before mutations when data-incarnation discovery is required; call `resetSession()` when the principal changes.
