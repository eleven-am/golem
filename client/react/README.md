# @eleven-am/golem-react

React hooks for the Go backend, using your existing TanStack Query client.

```sh
npm install @eleven-am/golem-react @eleven-am/golem-client @tanstack/react-query react gql.tada graphql graphql-ws
```

Wrap the same QueryClient with QueryClientProvider and GolemProvider. The guide covers live/static queries, mutations, pagination and session changes.

Use matching 0.3.1 client packages with React 18 or 19. GraphQL 16 supports Node 20.19; GraphQL 17 requires Node 22, 24 or 26 and later.
