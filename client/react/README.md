# @eleven-am/golem-react

React bindings for the golem live GraphQL client: `GolemProvider`, `useGolemQuery`, `useGolemInfiniteQuery`, `useGolemMutation`, `useGolemStatus` and `useGolemStaticQuery`.

```sh
npm install @eleven-am/golem-react @eleven-am/golem-client @tanstack/react-query react
```

See the [client README](../README.md) for setup, the hooks, live status, errors and the server requirements.
