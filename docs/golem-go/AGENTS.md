# Golem (Go): a working guide for an AI agent

**Describes go/v0.8.7 and the TypeScript client 0.2.1.** Module path:
`github.com/eleven-am/golem/go`. The `go/` suffix is part of the path. Tags
are `go/vX.Y.Z`; a plain `vX.Y.Z` tag belongs to the TypeScript packages in the
same repository and does not describe this module. The module needs Go 1.26.

```
go get github.com/eleven-am/golem/go@v0.8.7
go install github.com/eleven-am/golem/go/cmd/golem@v0.8.7
```

Keep the CLI and the library on one version. Generated code carries a contract
format; a build generated by an older CLI stops at startup with "generated
contract format N predates this golem".

Front end (needs a server at go/v0.8.3 or later):

```
npm install @eleven-am/golem-client@0.2.1 @eleven-am/golem-react@0.2.1 @tanstack/react-query react gql.tada graphql graphql-ws
```

This file is meant to be enough to build with golem without reading its
source. Every Go code block passes `go vet` against go/v0.8.6, and go/v0.8.7 changed no public Go API (fragments inside
a complete program; schema-package blocks are files of the verified example).
The end-to-end program in section 27 was generated, migrated and run as shown
against SQLite, and with the provider swapped, against PostgreSQL. Where the shipped docs and the code disagree, this file
follows the code and says so.

## 1. Rules that bite

1. **Every exposed model needs a policy.** There is no implicit allow; a model
   without `DefinePolicy` fails `inspect` and `generate` with
   `P1_BINDING_POLICY_REQUIRED`.
2. **`DefinePolicy` must be a pure function of the actor.** Built policies are
   cached per actor (section 5). A policy that reads the clock, a global or the
   database is frozen at its first result. Put such inputs on the actor in
   `ResolvePrincipal`.
3. **A mutation returns nothing you did not select**, not even the ID. Pass
   `X.Select(X.ID)` as the last argument (section 7). This bites custom
   mutations too: a resolver that returns the row of an `Upsert` or `Create`
   made without `Select` fails over GraphQL with
   `COMMITTED_RESULT_UNAVAILABLE` ("result row has no identity") after its
   writes committed. Verified.
4. **`Get()` returns `(value, present)`.** It reports `false` for an
   unselected field, a stored null and a policy-masked field. Never ignore the
   second return.
5. **Migration history before generation, and regenerate after every schema
   change.** `golem generate` refuses until `golem migration new` has written a
   history for every declared provider. Regenerating also rewrites the client
   manifest; ship it to the front end, or every live request fails with
   `GOLEM_CONTRACT_MISMATCH`. Run `golem check` in CI.
6. **Pass `--schema` to every command and run from the module root.**
   `migrations/` and `.golem/` are written relative to the working directory.
   Run `go mod tidy` after the first `generate` (the generated `golemgqlgen/`
   imports gqlgen).
7. **Use `internal`, not `hidden`, for server-only fields** such as API-key
   hashes. `hidden` removes the field from the generated Go API as well;
   `internal` keeps it for Go and system code and removes it from GraphQL,
   introspection, event payloads and the manifest.
8. **A required field that only a `BeforeCreate` hook sets must be declared
   `golem.GraphQLHookOwned(...)`**, or the create is refused as
   `BAD_USER_INPUT` before the hook runs.
9. **Use `golem.HookEnqueue` or `tx.Enqueue`, never `AfterCommit`, for a job
   that must exist.** An after-commit hook runs after the commit is durable; a
   crash between the two loses the job.
10. **`System()` bypasses every policy and runs no hooks.** A hook is never the
    owner of an invariant that must hold for system writes, and a
    `HookEnqueue` in a hook does not fire for rows `System()` writes. Never put
    `System()` behind a request.
11. **One call chain per transaction.** Never use one `tx` from several
    goroutines; an overlapping call fails at once with `P4_RUNTIME_TRANSACTION`.
    Inside a hook, call with the hook's own context or its executor.
12. **Never cancel a job by an ID taken from arguments.** Read the job ID in
    the same transaction from a row the caller's policy allowed, then call
    `tx.CancelJob`.
13. **Guard status writes against a concurrent cancel or failure.** A handler's
    success write is a conditional `UpdateMany` that matches the status it
    expects (and the job ID for a failure callback); zero rows means someone
    else won. Reading the status first is not enough on PostgreSQL.
14. **Upgrade every worker before relying on `OnJobFailed`.** A go/v0.8.2
    worker fails exhausted leases without calling it. Every process that
    registers the job type must register its callback, and the callback may run
    more than once.
15. **Any `AfterCommit*` hook makes `Config.AfterCommitError` mandatory**;
    `Open` fails with `P4_RUNTIME_CONFIG` without it.
16. **A model with `golem.Subscriptions` makes `EventTransport` and
    `ReportEventOperator` mandatory** (`GOLEM_EVENT_CONFIG` at `Open`), and
    events flow only while
    `RunEventPublisher` runs. A stream whose rule or filter reaches another
    model needs `Subscriptions` on that model too, or it is refused with
    `GOLEM_SUBSCRIPTION_INVALID` / `DEPENDENCY_UNOBSERVABLE`.
17. **Every live socket needs a deadline.** Set the credential expiry as the
    principal context's deadline, or mark an expiry-free principal with
    `golem.WithoutCredentialExpiry` and set `EventLimits.RevalidateEvery`.
    Otherwise subscriptions are refused with `GOLEM_PRINCIPAL_DEADLINE_REQUIRED`.
18. **Streams end, and rows leave.** Handle `GOLEM_SUBSCRIPTION_RESYNC` and
    `GOLEM_SUBSCRIPTION_OVERFLOW` by refetching and resubscribing, and handle
    `golem.EventExited` like a delete for the list you hold.
19. **Drain the event outbox before an upgrade that changes event formats.**
    0.6→0.7, 0.7→0.8.0 and 0.8.0→0.8.1 each need it (section 29).
20. **You can link only to rows you can read.** An unreadable target behaves
    exactly like a missing one.
21. **An upsert's or `ConnectOrCreate`'s create input must set every field of
    its unique target**, whichever branch you expect to run.
22. **A write touching more than `MutationLimits.MaxTouchedRows` rows (1,000,
    also the ceiling) is refused whole** with `LIMIT_EXCEEDED`.
23. **Every list a custom operation or computed field returns declares its
    maximum** with `golem.MaxItems` or `golem.GraphQLList(type, max)`, or
    `generate` fails with `P5_GRAPHQL_LIST_MAX_REQUIRED`.
24. **`golem.ActorFrom` works in hooks and in custom operations.** Since
    go/v0.8.6 a custom query receives the caller's actor over GraphQL or from
    Go through the generated `Query`, and a custom mutation over GraphQL or
    through `Mutate`. Before go/v0.8.6 a custom query got the zero actor and
    could not be called from Go with one, so a server older than that must let
    the caller's policy scope the query instead of filtering on the actor.
    Calling a resolver function directly skips the actor.
25. **Never hand-edit `zz_golem_*`, and never change a `golem:"id=..."`
    identity.**
26. **On SQLite, writes to a full-text-indexed table need a connection opened
    by golem's SQLite provider.**
27. **Queue handlers must honour `ctx.Done()` and be idempotent.** Delivery is
    at least once.
28. **Golem owns `golem_queue`.** An index you add to it stops startup.
29. **Branch on codes and reasons, never on message text.**

## 2. What golem is

You declare the data model as Go structs plus one authorization policy per
model. The `golem` CLI turns that into reviewed migrations and generated Go
code: a typed client for reads, writes, relations and transactions, plus a
durable queue, change events with row versions, a GraphQL server with live
subscriptions, a TypeScript client manifest, full-text search and semantic
search.

**Authorization is compiled into SQL.** A policy is a predicate, not a
callback: it becomes part of the WHERE clause of every statement golem runs,
so an unauthorized row is never read rather than read and then filtered.

## 3. The workflow

```
golem inspect          --schema ./notes                        # the derived model, as JSON
golem migration new    --schema ./notes --name init            # history first
golem generate         --schema ./notes --app-out ./notes      # then code
go mod tidy
golem migration apply  --provider sqlite --dsn "file:notes.db"
golem check            --schema ./notes --app-out ./notes      # CI
golem doctor           --provider sqlite --dsn "file:notes.db" --schema ./notes
```

After any schema edit: `migration new`, then `generate`, then
`migration apply`. Generation before a history fails with:

```
generated applications require a reviewed non-empty migration history for
every declared provider; create the initial migration before generating
```

An edit that changes no table (a GraphQL option, a hook, a custom operation)
needs only `generate`; `migration new` refuses it with "contract-only changes
belong to generate".

| Command | What it does |
|---|---|
| `inspect --schema ./p` | Prints the logical model as JSON. Exits 1 with a diagnostic such as `P1_BINDING_POLICY_REQUIRED`. |
| `migration new --schema ./p --name slug [--approve id ...]` | Writes `migrations/`: per-provider SQL, manifest, before/after snapshots. Refuses until every operation needing review is approved, listing them all at once. |
| `migration plan --schema ./p [--provider p]` | What `migration new` would produce now. Read-only. |
| `migration plan --migration 0002_x [--provider p]` | A written migration's operations, risk labels and warnings. Do not combine with `--schema`. |
| `migration backfill attach --migration id --field Model.Field --file path` | Attaches a reviewed backfill (PostgreSQL-only schemas, section 22). |
| `migration apply --provider p --dsn dsn` | Applies pending migrations. |
| `generate --schema ./p --app-out ./p` | Writes `zz_golem_*.gen.go`, `zz_golem_graphql.schema.graphqls`, `zz_golem_client.gen.ts`, `golemgqlgen/` and `.golem/` fingerprints. |
| `check --schema ./p --app-out ./p` | Fails if generated code or the manifest no longer matches the schema or was hand-edited. |
| `doctor --provider p --dsn dsn --schema ./p` | Reports `capabilities`, `history`, `schema` (drift) and `generation` for a live database. |
| `version` | Build version. |

Commit `migrations/`, `.golem/`, and every generated file.

## 4. Declaring a schema

The schema of the verified example (section 27). `Principal` lives in the
schema package because custom operations name `Caller[Principal]`.

```go
// notes/schema.go
package notes

import (
	"time"

	"github.com/eleven-am/golem/go/golem"
)

type Principal struct {
	UserID        golem.UUID
	Authenticated bool
}

type Actor struct {
	UserID        golem.UUID
	Authenticated bool
}

type Status string

const (
	StatusQueued    Status = "queued"
	StatusSucceeded Status = "succeeded"
	StatusFailed    Status = "failed"
	StatusCanceled  Status = "canceled"
)

func (Status) GolemEnum() golem.EnumSpec[Status] {
	return golem.DefineEnum(
		golem.EnumValue(StatusQueued),
		golem.EnumValue(StatusSucceeded),
		golem.EnumValue(StatusFailed),
		golem.EnumValue(StatusCanceled),
	)
}

type Author struct {
	_ struct{} `golem:"model;id=example.notes.Author;table=authors;graphql=Author"`
	_ struct{} `golem:"unique=uq_authors_handle(handle)"`

	ID      golem.UUID `db:"id" golem:"id=example.notes.Author.ID;pk;default=uuid"`
	Handle  string     `db:"handle" golem:"type=varchar(40)"`
	KeyHash string     `db:"key_hash" golem:"unique;internal;system;type=varchar(64)"`
	Notes   []Note     `db:"-" golem:"relation=has_many;fields=id;references=author_id"`
}

type Note struct {
	_ struct{} `golem:"model;id=example.notes.Note;table=notes;graphql=Note"`
	_ struct{} `golem:"index=idx_notes_author(author_id,id)"`

	ID        golem.UUID         `db:"id" golem:"id=example.notes.Note.ID;pk;default=uuid"`
	AuthorID  golem.UUID         `db:"author_id" golem:"id=example.notes.Note.AuthorID;immutable"`
	Title     string             `db:"title" golem:"type=varchar(200)"`
	Body      string             `db:"body" golem:"type=varchar(4000)"`
	Summary   golem.Null[string] `db:"summary"`
	Published bool               `db:"published" golem:"default=false"`
	CreatedAt time.Time          `db:"created_at" golem:"default=now;readonly"`
	UpdatedAt time.Time          `db:"updated_at" golem:"updated;readonly"`
	Author    *Author            `db:"-" golem:"relation=belongs_to;fields=author_id;references=id;immutable"`
	Comments  []Comment          `db:"-" golem:"relation=has_many;fields=id;references=note_id"`
}

type Comment struct {
	_ struct{} `golem:"model;id=example.notes.Comment;table=comments;graphql=Comment"`

	ID     golem.UUID `db:"id" golem:"id=example.notes.Comment.ID;pk;default=uuid"`
	NoteID golem.UUID `db:"note_id" golem:"id=example.notes.Comment.NoteID"`
	Body   string     `db:"body" golem:"type=varchar(500)"`
	Note   *Note      `db:"-" golem:"relation=belongs_to;fields=note_id;references=id"`
}

type Export struct {
	_ struct{} `golem:"model;id=example.notes.Export;table=exports;graphql=Export"`

	ID              string     `db:"id" golem:"id=example.notes.Export.ID;pk;type=varchar(64)"`
	OwnerID         golem.UUID `db:"owner_id"`
	JobID           string     `db:"job_id" golem:"type=varchar(64)"`
	Status          Status     `db:"status" golem:"default=queued"`
	CancelRequested bool       `db:"cancel_requested" golem:"default=false"`
	ErrorCode       string     `db:"error_code" golem:"type=varchar(64)"`
	Result          string     `db:"result" golem:"type=varchar(200)"`
}

func (Comment) GolemModel() golem.ModelSpec[Comment] {
	return golem.DefineModel(
		golem.RelationOptions(Comments.Note).OnDelete(golem.Cascade),
	)
}

func (Note) GolemModel() golem.ModelSpec[Note] {
	return golem.DefineModel(
		golem.Subscriptions[Note](),
		golem.GraphQL[Note](golem.GraphQLHookOwned(Notes.AuthorID)),
		golem.RelationOptions(Notes.Author).OnDelete(golem.Cascade),
		golem.FullTextIndex("content",
			golem.FullTextField(Notes.Title, 3),
			golem.FullTextField(Notes.Body, 1),
			golem.TextFolding(golem.FoldDiacritics),
			golem.TextPrefix(2, 3),
		),
	)
}

func (Export) GolemModel() golem.ModelSpec[Export] {
	return golem.DefineModel(
		golem.GraphQL[Export](golem.GraphQLOperations(golem.GraphQLFindOne, golem.GraphQLFindMany)),
		golem.Subscriptions[Export](),
	)
}

func DefineSchema(schema *golem.Schema) {
	golem.SchemaName(schema, "notes")
	golem.Actor[Actor](schema)
	golem.Model[Author](schema)
	golem.Model[Note](schema)
	golem.Model[Comment](schema)
	golem.Model[Export](schema)
	golem.Providers(schema, golem.SQLite, golem.PostgreSQL)
}
```

`Notes`, `Authors`, `Comments` and `Exports` are generated accessors (the
plural of the model name). They exist only after `generate`; the schema file
may reference them before that, and since go/v0.6.2 schema-package code may use
every generated symbol.

### Hard constraints

- `DefineSchema` must call `golem.SchemaName` (`P1_SCHEMA_NAME_MISSING`) and
  accepts only direct `golem.*` calls: no loops, `if`, helpers or variables. `GolemModel()` is exactly one `return golem.DefineModel(...)` of
  literal `golem.*` calls. Struct embedding is refused
  (`P1_MODEL_FIELD_SHAPE`).
- Scalars: `bool`, `int16`, `int32`, `int64`, `float32`, `float64`, `string`,
  `[]byte`, `time.Time`, `golem.UUID`, `golem.Decimal`, `golem.Date`,
  `golem.Time`, `golem.JSON[T]`, `golem.List[T]` (of scalars), `golem.Null[T]`
  (fields `Value`, `Valid`). Plain `int` is refused (`P1_TYPE_GO_UNSUPPORTED`).
- Every struct field is a column or a relation. `db:"-"` marks a relation.
- Enums: a string type with `GolemEnum()`. Give every constant the type
  explicitly; an untyped one fails with `P1_ENUM_VALUE_CONSTANT`.
- `relation=many_to_many` is refused (`P1_RELATION_IMPLICIT_M2M_UNAVAILABLE`):
  declare the join model with two `belongs_to` relations. `through=`,
  `source=` and `target=` parse but do nothing.
- Two relations between the same pair of models need `name=` on both sides.
- No soft delete, no down migrations. Back up before `migration apply`.

### Tags on a blank `_ struct{}` field (table level)

| Key | Meaning |
|---|---|
| `model` | marks the struct as a model |
| `id=` | canonical identity, stable across Go and table renames |
| `renameFrom=` | one-time claim of a previous identity, for a model without `id=` |
| `table=` | physical table name |
| `graphql=` | GraphQL type name |
| `primary=name(cols)` | composite primary key |
| `unique=name(cols)` / `index=name(cols)` | unique constraint / index; columns are **db column names** |

### Tags on a real field (column level)

| Key | Meaning |
|---|---|
| `id=` / `renameFrom=` | canonical field identity / one-time claim of a previous one |
| `pk` | primary key |
| `unique` | single-column unique key; a non-null one gets a `By<Field>` selector (a `golem.Null[T]` field gets none) |
| `default=uuid` / `default=now` | a value golem supplies on create; **no column `DEFAULT` is emitted** |
| `default=<literal>` | a column `DEFAULT` in the database (`default=false` emitted `"published" INTEGER NOT NULL DEFAULT 0` on SQLite) |
| `default=identity` | a database identity column; signed integers only |
| `type=` | physical type, such as `varchar(200)`, `json`, `decimal(p,s)` |
| `readonly` | no caller may write it |
| `updated` | set to the mutation time on every update |
| `immutable` | writable on create, never on update |
| `system` | only system clients and hooks may write it; a caller naming it is refused |
| `internal` | kept in the Go and system API (lookups, filters, order); absent from GraphQL, introspection, event payloads and the manifest |
| `hidden` | excluded from the generated API altogether |
| `writeonly` | writable, never readable |
| `graphql=` | GraphQL field name |
| `relation=belongs_to` / `has_one` / `has_many` | relation kind |
| `fields=` / `references=` | local and foreign columns of the relation |
| `name=` | pairs the two sides when a model has two relations to one target |

**`internal` rules.** It combines with everything except `hidden`. A primary
key cannot be `internal` (`P1_GOLEM_TAG_INTERNAL_PRIMARY_KEY`). On a model with
a GraphQL create root, a required `internal` field with no default must also be
`system` or hook-owned (`P8_GRAPHQL_INTERNAL_CLIENT_REQUIRED`), and a unique
one must be `system`. Kernel-mode schemas have no such requirement. Verified:
`KeyHash` above appears nowhere in the SDL or `zz_golem_client.gen.ts`, and
`FindUnique(ctx, Authors.ByKeyHash.Value(hash))` works from Go.

**Writing a `system` field.** The generated field has no `Create`/`Set` of its
own. Use the system field set: `Authors.System().KeyHash.Create(v)` (and
`.Set(v)`), on a system client or inside a hook.

**Reserved names.** A field or column named `GolemVersion`, `_version`,
`golem_version` or `_golem_version` is refused (row versions, section 14).

### Model options (`GolemModel()`)

- `golem.Subscriptions[M](golem.DeleteSnapshot[M](fields...))`: change events
  (section 14).
- `golem.RelationOptions(X.Rel).OnDelete(golem.Cascade)` (also `SetNull`,
  `SetDefault`): section 10.
- `golem.Check("name", X.F.Expr().GTE(0))`: a database check over the row's
  own fields, combined with `And`, `Or`, `Not`.
- `golem.FullTextIndex(...)`: section 18. `golem.SemanticIndex(...)`:
  section 19.
- `golem.GraphQL[M](...)` with `GraphQLOperations(GraphQLFindOne,
  GraphQLFindMany, GraphQLCreate, GraphQLUpdate, GraphQLUpsert, GraphQLDelete,
  GraphQLUpdateMany, GraphQLDeleteMany, ...)`, `GraphQLHookOwned(fields...)`,
  `GraphQLHidden()`.

Declaring an optimistic-concurrency version token removes the nested relation
methods and the batch writes for that model.

## 5. Policies

Every exposed model needs `DefinePolicy`. There is no implicit allow.

```go
// notes/policies.go
package notes

import "github.com/eleven-am/golem/go/golem"

func (Author) DefinePolicy(rules *golem.Rules[Author], actor Actor) {
	rules.CanRead(golem.All[Author]())
	if actor.Authenticated {
		own := Authors.ID.Eq(actor.UserID)
		rules.CanCreate(own)
		rules.CanDelete(own)
	}
}

func (Note) DefinePolicy(rules *golem.Rules[Note], actor Actor) {
	published := Notes.Published.Eq(true)
	if !actor.Authenticated {
		rules.CanRead(published)
		return
	}
	own := Notes.AuthorID.Eq(actor.UserID)
	rules.CanRead(published.Or(own))
	rules.CanCreate(own)
	rules.CanUpdate(own)
	rules.CanDelete(own)
	rules.CannotReadFields(own.Not(), Notes.Summary)
	rules.CannotUpdateFields(golem.All[Note](), Notes.Published)
	golem.Within(rules, SetPublished).CanUpdateFields(own, Notes.Published)
}

func (Comment) DefinePolicy(rules *golem.Rules[Comment], actor Actor) {
	rules.CanRead(golem.All[Comment]())
	if actor.Authenticated {
		rules.CanCreate(golem.All[Comment]())
	}
}

func (Export) DefinePolicy(rules *golem.Rules[Export], actor Actor) {
	if !actor.Authenticated {
		return
	}
	owned := Exports.OwnerID.Eq(actor.UserID)
	rules.CanRead(owned)
	rules.CanCreate(owned)
	rules.CanUpdate(owned)
}
```

`Rules` offers `CanRead/Create/Update/Delete`, their `Cannot…` forms, and
field-level `CanReadFields`, `CannotReadFields`, `CanCreateFields`,
`CannotCreateFields`, `CanUpdateFields`, `CannotUpdateFields`, each taking a
predicate and one or more fields. Predicates compose with `.And`, `.Or`,
`.Not()`, and `golem.And/Or/Not`. A predicate is pure data: anything a rule
needs that is not a column goes on the `Actor`, computed in
`ResolvePrincipal`. `golem.Within(...)` grants writes to one operation
(section 13).

### Policies are cached per actor

`ResolvePrincipal` runs on every `ForPrincipal`, so revocation takes effect on
the next call; each model's `DefinePolicy` runs at most once per distinct actor
(keyed by value; an actor holding a pointer, slice, map, channel or function is
rebuilt every call; with `SnapshotActor`, caching needs `PolicyCacheKey`).
`Config.PolicyCache` takes `MaxActors` (1,024), `TTL` and `Disabled`.
`application.InvalidatePolicies()` drops the cache and ends every open stream
with `RESYNC`. A model whose policy cannot be built fails only the calls that
need it (`UNAUTHENTICATED: principal policy could not be established`).
A zero actor from `ResolvePrincipal` gets the anonymous policy; an error
refuses with `UNAUTHENTICATED`.

### How policies are proved

- **Relation checks see only readable rows**, everywhere a policy applies.
  `Comments.Post.Is(Posts.Priority.Eq(0))` need not restate the post's read
  rule; `Rel.IsNull()` is true when the reference points at an unreadable row.
- **Write rules narrow to readable rows.** A single update or delete of a row
  the caller cannot read, or that its rule does not match, is `NOT_FOUND`
  (verified); batches skip such rows. No grant at all is `FORBIDDEN` /
  `NOT_GRANTED` before planning; an upsert's create branch needs a create grant.
- A field the caller can never read cannot filter, order, page or select
  (`FIELD_NOT_READABLE`). A cycle, more than `MaxRelationDepth` (5) hops, or a
  statement limit the policy alone exceeds is `POLICY_INVALID`; break cycles by
  testing a foreign key directly.
- **The one leak a policy cannot close is a unique constraint**: a collision
  with an unreadable row is still `CONFLICT`. Make secret keys opaque or scope
  them by owner.

## 6. Opening an application and reading

```go
database, err := sqlite.Open(ctx, sqlite.Config{DataSourceName: "file:notes.db"})
// or postgresql.Open(ctx, postgresql.Config{DataSourceName: dsn, Pool: postgresql.PoolConfig{...}})

application, err := notes.Open(ctx, notes.Config[notes.Principal]{
	Database: database,
	ResolvePrincipal: func(_ context.Context, p notes.Principal) (notes.Actor, error) {
		return notes.Actor{UserID: p.UserID, Authenticated: p.Authenticated}, nil
	},
})
caller, err := application.ForPrincipal(ctx, notes.Principal{UserID: id, Authenticated: true})
system := application.System()
```

`Principal` is your own type (whatever your authentication produces);
`ResolvePrincipal` turns it into the `Actor` policies see. `ForPrincipal`
applies policy to everything; `System()` applies none and runs no hooks.

Other `Config` fields: `Queue`, `QueueFailed` (section 20), `Embeddings`
(section 19), `EventTransport`, `EventLimits`, `ReportEventOperator`,
`CDCAdapters`, `HistoricalEventBundles` (section 14), `Observer` (section 24),
`ReadLimits`, `MutationLimits`, `AnalyticsLimits`, `AfterCommitError`
(section 12), `SnapshotActor`, `SnapshotPrincipal`, `PolicyCache`,
`PolicyCacheKey` (section 5), `SubscriptionPrincipalKey` (section 14),
`AuditPrincipal` and `ReportScopedQuery` (both required for scoped reads).

`Open` refuses a database whose schema does not match the generated code
(`P3_RUNTIME_DRIFT`); apply migrations first and use `golem doctor`. `Open`
also refuses while any database connection is checked out: call it before
anything else touches the handle. Pool tuning lives in
`postgresql.Config.Pool`; `Open` re-applies the pool profile.

### Reading

```go
page, err := caller.Notes.FindMany(ctx,
	notes.Notes.Where(notes.Notes.AuthorID.Eq(authorID).And(notes.Notes.Published.Eq(true))),
	notes.Notes.OrderBy(notes.Notes.CreatedAt.Desc(), notes.Notes.ID.Asc()),
	notes.Notes.Take(20),
	notes.Notes.Select(notes.Notes.ID, notes.Notes.Title, notes.Notes.Author.Select(notes.Authors.Handle)),
)
for _, row := range page {
	author, ok := golem.One(row, notes.Notes.Author.ToOne).Get()
	if ok {
		handle, _ := golem.Value(author, notes.Authors.Handle).Get()
		_ = handle
	}
}
first, found, err := caller.Notes.FindFirst(ctx, notes.Notes.Where(notes.Notes.Title.Compare(golem.ASCIIInsensitive()).StartsWith("draft")))
count, err := caller.Notes.Count(ctx, notes.Notes.Where(golem.All[notes.Note]()))
one, err := caller.Notes.FindUnique(ctx, notes.Notes.ByID.Value(id))
withComments, err := caller.Notes.FindMany(ctx, notes.Notes.Where(notes.Notes.Comments.Some(notes.Comments.Body.Contains("thanks"))))
byKey, err := system.Authors.FindUnique(ctx, notes.Authors.ByKeyHash.Value(hash))
version, err := caller.Notes.FindUnique(ctx, notes.Notes.ByID.Value(id), notes.Notes.Select(notes.Notes.GolemVersion))
```

- Read options: `Where`, `OrderBy`, `Take`, `Skip`, `Distinct`, `Cursor`,
  `Select`, `Include`, `Omit`. `Where` takes exactly one predicate;
  `golem.All[M]()` means "everything the policy permits".
- **There is no default row cap.** `ReadLimits.MaxTake` is unlimited when
  zero. Pass `Take`.
- Relations: `golem.One(row, X.Rel.ToOne)`, `golem.Many(row, X.Rel.ToMany)`,
  `golem.RelationCount(row, X.Rel.ToMany)`. To-many predicates: `Some`,
  `Every`, `None`; to-one: `Is`, `IsNot`, `IsNull`, `IsNotNull`.
- `By<Field>` selectors exist only for non-null unique fields (never for a
  `golem.Null[T]` field), and are used inside `FindUnique(ctx, X.ByField.Value(v))`.
  Selectors are generated per non-null key: `ByID`, `ByHandle`,
  `ByKeyHash`.
- `X.GolemVersion` is the row version of a model with `Subscriptions`
  (section 14); it works in `Select` and predicates and is never writable.
- `Explain…` methods on caller clients return a `queryplan.Report`.

**Text comparison is exact by default.** `Eq`, `Contains`, `StartsWith`,
`EndsWith` are case-sensitive. `Field.Compare(golem.ASCIIInsensitive())` folds
ASCII letters only (`É` does not find `é`). Use a full-text index for
Unicode-aware matching.

**Reading values.** `golem.Value(row, field)` returns a `ReadValue`. `Get()`
gives `(value, present)`. `State()` separates `golem.ReadUnselected`,
`golem.ReadNull`, `golem.ReadPresent`. A field masked by policy reads as
`ReadNull`, indistinguishable from a stored null.

## 7. Writing

```go
author, err := system.Authors.Create(ctx,
	notes.Authors.Create(notes.Authors.Handle.Create("ada"), notes.Authors.System().KeyHash.Create(hash)),
	notes.Authors.Select(notes.Authors.ID),
)
id, ok := golem.Value(author, notes.Authors.ID).Get()

_, err = caller.Notes.Update(ctx, notes.Notes.ByID.Value(noteID),
	notes.Notes.Update(notes.Notes.Title.Set("renamed"), notes.Notes.Summary.Null()),
	notes.Notes.Select(notes.Notes.ID, notes.Notes.UpdatedAt),
)
_, err = caller.Notes.UpdateMany(ctx, notes.Notes.Title.Eq("draft"), notes.Notes.UpdateMany(notes.Notes.Body.Set("")))
_, err = caller.Notes.Delete(ctx, notes.Notes.ByID.Value(noteID), notes.Notes.Select(notes.Notes.Title))
```

- Create values use `Field.Create(v)` (nullable: `CreateNull()`); update values
  `Field.Set(v)` (nullable: `Null()`). A `readonly`, `immutable` (on update) or
  `system` field has no caller builder; `system` fields are written through
  `X.System().Field`.
- `UpdateMany` and `DeleteMany` return `int64` counts; the rest return a
  `golem.Row` holding **only the projection you passed**.
- Nested relation builders: to-one `Create`, `Connect`, `ConnectOrCreate` (plus
  `Update`, `Upsert` when the key is not immutable); to-many `Create`,
  `CreateMany`, `Connect`, `ConnectOrCreate`, `Disconnect`, `Set`, `Update`,
  `UpdateMany`, `Upsert`, `Delete`, `DeleteMany`.
- **Nested operations on one relation run in a fixed order**, whatever order
  you list them: `Delete`, `DeleteMany`, `Disconnect`, `Set`; then `Update`,
  `UpdateMany`, `Upsert`; then `Create`, `CreateMany`, `Connect`,
  `ConnectOrCreate`. `DeleteMany` + `Create` relinks in one call. An `Update`,
  `Delete` or `Disconnect` naming a row the same write creates or connects is
  `NOT_FOUND`; make it a second call. A later nested operation that removes a
  row the write created or updated fails the write with `CONFLICT`.
- **Upsert and `ConnectOrCreate`.** The create input must set every field of
  the unique target to the target's value, or the call is refused with
  `BAD_USER_INPUT` before either branch runs. A foreign-key field of the target
  is satisfied by a `Connect` on its relation or by the nested parent's value.
- `Increment`/`Decrement` on a foreign-key field is refused.
- Strings containing NUL are refused. An empty `[]byte` stays empty.
  `golem.NewDecimal(0, scale)` equals `golem.Decimal{}`.
- **Datetimes truncate.** Writes truncate toward the past to the field's
  precision (microseconds at most), including `default=now` and `updated`. A
  filter operand finer than a microsecond is rewritten exactly (`Eq(v)` matches
  nothing, `Ne(v)` everything); a unique selector, cursor, list operator, scoped
  read or analytics operand that fine is `BAD_USER_INPUT` / `VALUE_PRECISION`.
  Compare against the value golem returns, not the one you wrote.

## 8. Transactions

```go
err := caller.Transaction(ctx, func(tx *notes.CallerTx[notes.Principal]) error {
	if _, err := tx.Notes.Create(ctx, input); err != nil {
		return err
	}
	_, err := tx.Enqueue(ctx, pending)
	return err
})
```

Returning an error rolls back everything, including the enqueued job.
`Transaction` on `Caller` and `System` takes options:

- `golem.Isolation(golem.Serializable)` (PostgreSQL; `golem.ReadCommitted` is
  the default). Use it only when every transaction that checks the invariant
  uses it, and always with `RetryConflicts`.
- `golem.RetryConflicts(n)`, `n` 1..10: rerun the callback after `CONFLICT`,
  up to `n` times in all. The callback must be safe to rerun. It also replays
  deterministic conflicts (an `ExpectVersion` mismatch), so it is for
  contention only. A PostgreSQL serialization failure inside `tx.Enqueue` or
  `tx.CancelJob` is a `CONFLICT` and is retried.

**Lock keys serialize a check-then-write.** Take them first, before any write:

```go
err := caller.Transaction(ctx, func(tx *notes.CallerTx[notes.Principal]) error {
	if err := tx.LockKeys(ctx, golem.MustLockKey("note-quota", authorID.String())); err != nil {
		return err
	}
	count, err := tx.Notes.Count(ctx, notes.Notes.Where(notes.Notes.AuthorID.Eq(authorID)))
	if err != nil || count >= limit {
		return err
	}
	_, err = tx.Notes.Create(ctx, input)
	return err
})
```

`golem.NewLockKey(namespace, parts...)` returns an error instead of panicking.
On PostgreSQL these are transaction advisory locks, across replicas; keys in
one call are taken in a fixed order. Taken after a row lock, a key fails at
once with `CONFLICT`. On SQLite `LockKeys` only validates.

**`SystemEscape`.** `notes.SystemEscape(tx)` returns a system client bound to
the same caller transaction. It skips every rule and hook; prefer `Within` or a
transaction operation (section 13). An escape taken from a transaction
operation's handle ends with the operation.

**A transaction serves one call chain at a time.** The chain is one call and
everything nested in it: the hooks it runs, calls made with a hook's own
context, calls through a hook's `HookExecutor`, and the hooks those run. Calls
made one after another always proceed. A call that overlaps the active call
without belonging to its chain fails immediately:

```
P4_RUNTIME_TRANSACTION: transaction used concurrently; a transaction serves one call chain at a time
```

That covers sibling goroutines started from the callback, a call inside a hook
with a context that is not the hook's own, and a second executor call started
while the first is running. A loop is just as fast: the transaction holds one
connection. Do slow non-database work before opening the transaction; hand
background work to `tx.Enqueue`. Calls after the callback returns are refused
with `P4_RUNTIME_TRANSACTION`.

## 9. Linking

**A caller can link only to a row it can read**, on every path that writes a
foreign key: create, update, update-many, upsert, nested `Connect`,
`ConnectOrCreate`, set and disconnect, through Go, `HookExecutor` and GraphQL.

- An unreadable target is reported exactly like a missing one. Verified: a
  direct key write to either returns `BAD_USER_INPUT`, and `Connect` to either
  returns `NOT_FOUND`.
- `Connect` needs **read** access to the target, not update access.
- Not checked: system clients, and foreign-key values written by hooks.

## 10. Cascades and concurrent writes

`golem.RelationOptions(Notes.Author).OnDelete(golem.Cascade)` makes a
dependent's lifetime belong to its parent; `SetNull` and `SetDefault` clear or
reset the reference.

- **Permission to delete the parent covers every dependent**, including rows
  the caller cannot read.
- Each cascaded row emits a `deleted` event and each cleared reference an
  `updated` event, in the same transaction (verified in section 27).
- **A write touching more than `MutationLimits.MaxTouchedRows` rows (1,000 by
  default and at most) is refused whole** with `LIMIT_EXCEEDED`, limit
  `touched_rows`. The count includes unreadable rows. Delete dependents in
  batches first.
- A dependent another write removes first is no longer affected; another write
  adding a row the cascade would remove fails the delete with `CONFLICT`.

**PostgreSQL concurrency.** Concurrent writes on the same rows do not deadlock:
one completes and the other waits or fails at once with `CONFLICT`. Retry
`CONFLICT`. Upserts and nested writes containing an upsert or `ConnectOrCreate`
retry by themselves, except inside your own transaction. `UpdateMany` and
`DeleteMany` change exactly the rows that match while they hold them. A single
update or delete whose target another write deleted or changed away is
`NOT_FOUND`. Write rows in the same order in every transaction. SQLite runs one
writer at a time.

## 11. Field modes, `system` and hooks together

- `immutable`: `Create` but no `Set`.
- `readonly`: neither.
- `system`: a caller naming it is refused (`BAD_USER_INPUT`). Hooks and system
  clients write it through `X.System().Field` or `golem.SetCreate`.
  `system;immutable` may not be rewritten on update, even by a hook.
- A field the caller's own input named stays refused whatever a hook does to
  it, so a hook cannot launder a caller's value.
- A caller cannot set a `system`, `readonly`, `hidden` or (on update)
  `immutable` foreign key through a relation either.

## 12. Hooks

Hooks are methods on the model with these exact names:

| Operation | Before | After (in transaction) | After commit |
|---|---|---|---|
| `FindOne`, `FindFirst`, `FindMany` | `Before<Op>(ctx, *<M><Op>Request) error` | `After<Op>(ctx, <M><Op>Result) error` | none |
| `Create`, `Update`, `Delete`, `UpdateMany`, `DeleteMany` | same shape | same shape | `AfterCommit<Op>(ctx, <M><Op>Result) error` |

There are no upsert or aggregate hooks (`P1_BINDING_HOOK_FORBIDDEN`); an
upsert runs the hooks of the branch it takes. **Hooks run only for caller
operations**, including those inside custom mutations and transaction
operations. Writes through `System()` or `SystemEscape` run none.

```go
// notes/hooks.go
package notes

import (
	"context"

	"github.com/eleven-am/golem/go/golem"
	"github.com/eleven-am/golem/go/queue"
)

type Welcome struct {
	NoteID string `json:"noteId"`
}

var WelcomeJob queue.Type[Welcome]

func (Note) BeforeCreate(ctx context.Context, request *NoteCreateRequest) error {
	actor := golem.ActorFrom[Actor](ctx)
	if !actor.Authenticated {
		return nil
	}
	return golem.SetCreate(request, Notes.AuthorID, actor.UserID)
}

func (Note) AfterCreate(ctx context.Context, result NoteCreateResult) error {
	id, ok := golem.Value(result.Row(), Notes.ID).Get()
	if !ok {
		return nil
	}
	pending, err := WelcomeJob.New(Welcome{NoteID: id.String()}, queue.Dedupe("welcome:"+id.String()))
	if err != nil {
		return err
	}
	_, err = golem.HookEnqueue(ctx, result.Executor(), pending)
	return err
}
```

- **`Before`** may change the request: `golem.SetCreate` sets a create field,
  including a `system` one. An error refuses the operation. Keep it free of side
  effects.
- **`After`** runs inside the write's transaction and sees `Row()`, `Before()`
  and `After()`, or `Count()` for batches. An error rolls the write back. Its
  `Executor()` reads and writes on the same transaction through
  `golem.HookFindManyRows`, `HookCreateRow`, `HookUpdateRow`, `HookDeleteRow`,
  `HookUpsertRow`, `HookUpdateManyRows`, `HookDeleteManyRows`. Each executor
  write runs in its own savepoint; a failed one leaves nothing behind and the
  hook can continue. The executor works only while the hook runs
  (`P4_RUNTIME_HOOK_EXECUTOR` afterwards).
- **`golem.HookEnqueue(ctx, result.Executor(), pending)`** (go/v0.8.3) enqueues
  a durable job on that transaction: it exists if and only if the write
  commits. It runs in its own savepoint, so the hook may handle a refusal and
  let the write commit without the job. A matching `queue.Dedupe` key returns
  the existing job's ID. Without `Config.Queue` it returns
  `queue.CodeConfigInvalid`, which rolls the write back unless the hook
  swallows it; `Open` cannot check this. It behaves the same in single-row,
  batch and nested hooks (go/v0.8.4), and the in-process worker wakes right
  after commit. The job type is a package variable because hooks have no handle
  to the registry; set it before `Open`. Verified: both notes created in
  section 27 ran their welcome job.
- **`AfterCommit`** runs after commit; its error cannot undo anything and goes
  to `Config.AfterCommitError`, which `Open` requires when any after-commit hook
  exists. It has no executor. Use it only for best-effort side effects.

```go
AfterCommitError: func(_ context.Context, failure golem.AfterCommitFailure) {
	log.Printf("after-commit hook failed: %s", failure.Operation())
},
```

- **`golem.ActorFrom[Actor](ctx)`** returns the caller's actor in hooks and in
  custom query and mutation resolvers (custom queries since go/v0.8.6, rule 24).
- **Input values.** `golem.RuntimeFreezeCreateInput` /
  `RuntimeFreezeUpdateInput` then `FrozenMutationField.Value()` give the same
  Go value on every path: the field's Go type, an enum as its wire `string`, a
  scalar list as a plain `[]T`.
- A panic in a hook becomes `generated hook panicked`.

## 13. Custom operations and `Within`

Three kinds of operation own writes:

| Kind | Declared with | Runs from | Receives |
|---|---|---|---|
| custom query | `golem.Query(graphql, "name", Fn, golem.MaxItems(...))` in `DefineGraphQL` | GraphQL, or Go through the generated `Query` (since go/v0.8.6) | `*Caller[P]`, args |
| custom mutation | `golem.Mutation(graphql, "name", Fn)` in `DefineGraphQL` | GraphQL, or Go through `Mutate` | `*Caller[P]`, args |
| transaction operation | `golem.TxOperation(ops, "name", Fn)` in `DefineOperations` | Go through `Run` on a `CallerTx` | `*CallerTx[P]`, args |

`golem.Query` declares a custom query; since go/v0.8.6 the generated
`Query[P, Args, R](ctx, caller, resolver, args)` runs it from Go with the
caller's actor, the read-side twin of `Mutate`. A resolver never receives `System`, a transaction
or a database; it may open `caller.Transaction` itself, and inside it use
`tx.Enqueue` and `tx.CancelJob`.

From the verified example's `notes/operations.go` (the export functions are in
section 21):

```go
// notes/operations.go (excerpt)
type DraftsArgs struct {
	Limit int32 `golem:"graphql=limit"`
}

type SetPublishedArgs struct {
	ID        golem.UUID `golem:"graphql=id"`
	Published bool       `golem:"graphql=published"`
}

func DefineGraphQL(graphql *golem.GraphQLSchema) {
	golem.Query(graphql, "drafts", Drafts, golem.MaxItems(50))
	golem.Mutation(graphql, "setPublished", SetPublished)
	golem.Mutation(graphql, "requestExport", RequestExport)
	golem.Mutation(graphql, "cancelExport", CancelExport)
}

func Drafts(ctx context.Context, caller *Caller[Principal], args DraftsArgs) ([]golem.Row[Note], error) {
	return caller.Notes.FindMany(ctx,
		Notes.Where(Notes.Published.Eq(false)),
		Notes.OrderBy(Notes.Title.Asc(), Notes.ID.Asc()),
		Notes.Take(int(args.Limit)),
		Notes.Select(Notes.ID, Notes.Title),
	)
}

func SetPublished(ctx context.Context, caller *Caller[Principal], args SetPublishedArgs) (golem.Row[Note], error) {
	return caller.Notes.Update(ctx, Notes.ByID.Value(args.ID),
		Notes.Update(Notes.Published.Set(args.Published)),
		Notes.Select(Notes.ID, Notes.Published, Notes.GolemVersion),
	)
}
```

### `Within`: a grant only an operation has

The policy in section 5 closes the generic surface with
`rules.CannotUpdateFields(golem.All[Note](), Notes.Published)` and grants the
field to one operation with
`golem.Within(rules, SetPublished).CanUpdateFields(own, Notes.Published)`.
Verified: `caller.Notes.Update` of `Published` is refused with `FORBIDDEN`,
and `notes.Mutate(ctx, caller, notes.SetPublished, args)` succeeds.

- Grants: `CanCreate`, `CanUpdate`, `CanDelete`, `CanCreateFields`,
  `CanUpdateFields`, plus `CanCount` and `CanAggregate` for transaction
  operations. No `Cannot*` verbs.
- Inside the operation a write is allowed when a covering grant or the
  caller's own policy allows it. Field modes still bind.
- The grant exists only while that resolver runs. The generic root,
  `caller.X.Create`, a direct call of the resolver function, a caller or
  goroutine that outlives it, and another mutation in the same document get the
  caller's usual error. A grant-dependent write reaching commit after the
  operation ended gets a retryable `CONFLICT`.
- `Within` must name a generated custom mutation or transaction operation;
  anything else fails that model's policy build.
- Prefer `Within` to `SystemEscape`: it grants one verb on the rows you name and
  keeps predicates, hooks and event authorization.

### Running operations from Go

```go
row, err := notes.Mutate(ctx, caller, notes.SetPublished, notes.SetPublishedArgs{ID: id, Published: true})

err = caller.Transaction(ctx, func(tx *notes.CallerTx[notes.Principal]) error {
	_, err := notes.Run(ctx, tx, notes.RetitleNote, notes.RetitleNoteArgs{ID: id, Title: "renamed"})
	return err
})
```

`Mutate` runs the resolver exactly as GraphQL dispatch does: grants, hooks,
actor, observation (`mutation.custom`). `Run` refuses a custom mutation and
`Mutate` a transaction operation (`P5_CUSTOM_OPERATION`). A transaction
operation runs on the transaction you pass; its grant ends when it returns, and
a handle it kept is refused with `P5_CUSTOM_OPERATION: operation has ended`.

```go
// notes/txops.go
package notes

import (
	"context"

	"github.com/eleven-am/golem/go/golem"
)

type RetitleNoteArgs struct {
	ID    golem.UUID
	Title string
}

func DefineOperations(operations *golem.Operations) {
	golem.TxOperation(operations, "retitleNote", RetitleNote)
}

func RetitleNote(ctx context.Context, tx *CallerTx[Principal], args RetitleNoteArgs) (string, error) {
	updated, err := tx.Notes.Update(ctx, Notes.ByID.Value(args.ID),
		Notes.Update(Notes.Title.Set(args.Title)), Notes.Select(Notes.Title))
	if err != nil {
		return "", err
	}
	title, _ := golem.Value(updated, Notes.Title).Get()
	return title, nil
}
```

### Counts an operation owns

Inside `Run`, `golem.Within(rules, Op).CanCount(pred)` widens the rows `Count`
sees, and `CanAggregate(pred, fields...)` the rows `Aggregate` sees, with only
the named fields usable as measures and filters (`MIN`/`MAX` disclose their
values). Nothing else is widened: not reads, `GroupBy`, events, explanations or
writes.

### What a custom operation returns

- A resolver returning `golem.Row[M]`, `[]golem.Row[M]` or lists of lists has
  every row **read again through the caller** with the client's selection, so
  relations, `_count`, policy and masks behave as on generated roots.
- In queries a row the caller cannot read or that was deleted is left out; a
  single missing result is `null`, or `NOT_FOUND` when non-null.
- A custom mutation never hides its commit. A failure after the resolver
  returned is `COMMITTED_RESULT_UNAVAILABLE` with `extensions.committed: true`
  (`reason: RESULT_NOT_READABLE` with `unreadable: N` when the caller cannot
  read the result). The row must carry its key, so give every write whose row
  you return a `Select` (rule 3).
- **Every list declares its maximum.** `golem.MaxItems(outermost, nested...)`
  on `Query`/`Mutation`, `golem.GraphQLList(type, max)` in a computed field.
  Returning more fails with `LIMIT_EXCEEDED`, limit `list_items`; the list is
  never shortened.

## 14. Events and subscriptions

### Setup

1. Add `golem.Subscriptions[M]()` to the model, and to every model a
   subscriber's rule or filter reaches.
2. At `Open`, pass `EventTransport` and `ReportEventOperator`.
3. Run `application.RunEventPublisher(ctx)` in a goroutine.
   `application.EventCapabilities().PublisherRunning()` reports readiness.

```go
transport, err := events.NewMemoryTransport(events.MemoryLimits{Buffer: 128})
// multi-process: nats.Open(ctx, database, nats.Config{URLs: []string{"nats://127.0.0.1:4222"}, SubjectPrefix: "notes"})
// (package github.com/eleven-am/golem/go/events/nats)
```

**The transactional outbox.** Every write to a subscribed model records a fact
in golem's outbox in the same transaction, so an event exists if and only if
the change committed. This holds for `System()` writes too: capture is decided
by the model, not the stance. The publisher claims committed facts and
publishes them through the transport; each subscriber's process judges each
event against that subscriber's policy.

**The publisher wake (go/v0.8.5).** A commit that recorded facts wakes the
in-process publisher at once, so events arrive in about 20 ms instead of
about 250 ms. A rolled-back write never wakes it. Polling remains the fallback
for other processes and for CDC.

**Transports.** `events.NewMemoryTransport` is process-local: run the publisher
and every subscriber in one process; other processes may write but must not
publish or subscribe. On PostgreSQL a second process-local publisher is
reported (`events.ObservationTopology`), or refused with
`EventLimits.RequireExclusiveProcessLocalPublisher`. `events/nats` publishes
to every process with the same `SubjectPrefix`; give each database its own.
Core NATS does not replay: losing the broker connection ends every open stream
with `RESYNC`.

### Subscribing in Go

`Events` is generated on **caller** clients only:

```go
stream, err := caller.Notes.Events(ctx,
	golem.EventWhere(notes.Notes.Published.Eq(true)),
	golem.EventSelect[notes.Note](notes.Notes.Title, notes.Notes.Published),
)
if err != nil {
	return err
}
defer stream.Close()
for {
	event, err := stream.Recv(ctx)
	if err != nil {
		return err
	}
	switch event.Metadata().Action() {
	case golem.EventCreated, golem.EventUpdated:
		if row, ok := event.Entity(); ok {
			apply(event.ID(), event.Metadata().Version(), row)
		}
	case golem.EventDeleted, golem.EventExited:
		forget(event.ID())
	}
}
```

Options: `golem.EventWhere(pred)`, `golem.EventSelect[M](fields...)`,
`golem.EventRecheck[M](interval, check)`. `Events` returns only once the
source is live; a cancelled wait is `GOLEM_SUBSCRIPTION_CANCELLED`, a closed
source `GOLEM_SUBSCRIPTION_SOURCE_CLOSED`. A deadline on one `Recv` call does
not end the stream: the error wraps the context's error and the next `Recv`
gets the next event.

### What an event carries

`Metadata()` gives the action, event ID, causation ID (shared by one
transaction), ordinal, recorded time and `Version()`. `ID()` is the typed key.
`Entity()` exists only with `EventSelect`, only for created and updated
events, and is the row as it is at delivery under your policy, not the values
written; a row gone by then is not delivered. Order across transactions is not
write order.

| Action | GraphQL `type` | Meaning |
|---|---|---|
| `golem.EventCreated` | `CREATED` | a readable row was created |
| `golem.EventUpdated` | `UPDATED` | a readable row changed, or started to match |
| `golem.EventDeleted` | `DELETED` | a row you could read was deleted; key only |
| `golem.EventExited` | `EXITED` | an update moved a row you could read out of your filter or read rule; key only; it can come back (go/v0.8.1) |

Verified in section 27: when Ada unpublished a note, Bob's stream (Bob may
read only published notes) received `exited`.

### Row versions (`_version`)

Every model with `Subscriptions` has a golem-owned row version (go/v0.8.1).
Each write golem issues gives the row a version higher than any that key has
committed; a recreated key starts above its deleted row; a delete keeps the
last version. GraphQL exposes `_version: String!` (decimal) on the type and
`version: String!` on every event; Go has the read-only `X.GolemVersion` and
`EventMetadata.Version() int64`. An event carries the version of the write
that produced it; its entity carries the `_version` it was read at. Compare as
integers and ignore events older than the row you hold. One sequence serves
the whole database (PostgreSQL `golem_row_version` with `CACHE 1`; SQLite a
one-row table); any other shape is drift. Writes outside golem do not stamp;
rows predating the upgrade hold 0 until their next write.

### Who receives what

- **Created and updated**: golem reads the changed row once per event and
  judges every subscriber against it (go/v0.8.1). Excluded subscribers cost
  nothing more; candidates run the full path (fresh principal resolution, read
  hooks, own read), which alone decides delivery. Exclusion uses the policy as
  it was when the stream opened: broadened access arrives on reopen,
  revocation is never late. Read hooks run once per candidate.
- **Deleted**: judged against the **delete snapshot** (key, forward foreign
  keys and bounded scalars by default; `golem.DeleteSnapshot[M](fields...)`)
  with three-valued logic. An undecidable read rule ends that subscriber's
  stream with `RESYNC`. A snapshot over `MaxDeleteSnapshotBytes` (64 KiB) keeps
  identity only.
- **Exited**: update facts store a before snapshot with the same fields. When
  an updated event finds no row for a subscriber: rule and filter true before
  → `EXITED`; either false → nothing; either unknown → `RESYNC`.
- **Reached models**: a rule or filter that reaches another model
  (`Comments.Post.Is(...)`) watches it; a change to a field it reads, on a row
  the subscriber could read before or now, ends the stream with `RESYNC`,
  reason `DEPENDENCY_CHANGED` (`events.ReasonOf`).

### Streams end with a code

`events.CodeOf(err)` returns the code:

| Code | Why | Do |
|---|---|---|
| `GOLEM_SUBSCRIPTION_CANCELLED` | you called `Close`, or the subscribe context ended | nothing |
| `GOLEM_SUBSCRIPTION_RESYNC` | events may have been missed: transport loss, an undecidable delete or exit, `InvalidatePolicies()`, or `DEPENDENCY_CHANGED` | reload, subscribe again |
| `GOLEM_SUBSCRIPTION_OVERFLOW` | this subscriber's queue (`EventLimits.SubscriberQueue`, 64) filled | reload, subscribe again; read faster |
| `GOLEM_SUBSCRIPTION_REVALIDATION` | the principal no longer resolves, a policy or shared read failed | re-authenticate, subscribe again |
| `GOLEM_SUBSCRIPTION_FORBIDDEN` | a re-check found the caller may no longer read the stream | stop |
| `GOLEM_SUBSCRIPTION_LIMIT` | a per-connection or per-principal cap was reached | close another stream |
| `GOLEM_SUBSCRIPTION_SOURCE_CLOSED` | shutdown, source failure, or an event the schema cannot decode | reconnect with backoff, reload |
| `GOLEM_SUBSCRIPTION_INVALID` | refused at open; reason `DEPENDENCY_UNOBSERVABLE` names a reached model without `Subscriptions` | fix the schema |

```go
func subscribe(ctx context.Context, caller *notes.Caller[notes.Principal], refetch func(context.Context) error) error {
	for {
		if err := refetch(ctx); err != nil {
			return err
		}
		stream, err := caller.Notes.Events(ctx, golem.EventWhere(notes.Notes.Published.Eq(true)))
		if err != nil {
			return err
		}
		for {
			event, err := stream.Recv(ctx)
			if err != nil {
				stream.Close()
				code, _ := events.CodeOf(err)
				if code == events.CodeSubscriptionResync || code == events.CodeSubscriptionOverflow {
					break
				}
				return err
			}
			if row, ok := event.Entity(); ok {
				_ = row
			}
		}
	}
}
```

### Re-checks and caps

`EventLimits.RevalidateEvery` (off; 1 s..24 h) re-resolves the principal and
re-checks every stream on a jittered interval, and bounds marked sockets
(section 15). `golem.EventRecheck[M]` and `GraphQLConfig.SubscriptionRecheck`
add your own check. `EventLimits.MaxSubscriptionsPerConnection` (32, at most
256) caps one WebSocket; `MaxSubscriptionsPerPrincipal` with
`Config.SubscriptionPrincipalKey` caps one principal per process.
`EventLimits.KeepAlive` (30 s) covers WebSocket and SSE.

### Change data capture

`Config.CDCAdapters` publishes changes written outside golem through your
adapter. Since go/v0.8.0 each batch is recorded in `_golem_outbox` before it is
published, and deletes are decided like ordinary ones; failures are
`GOLEM_CDC_INVALID` (too large, or a replay that differs) or
`GOLEM_CDC_UNAVAILABLE` (keep the checkpoint, retry). Since go/v0.8.1 images
carry `golem_version`, the emitter stamps the changed row in the fact's
transaction, and `CorrelatesGolemTransaction` must answer true for that stamp
or it loops. Give updates a `Before` image when you can; without it holders get
`RESYNC` instead of `EXITED`.

## 15. Serving GraphQL and the live protocol

```go
server, err := application.GraphQL(notes.GraphQLConfig[notes.Principal]{
	PrincipalFromContext: func(ctx context.Context) (notes.Principal, bool) {
		principal, ok := ctx.Value(principalKey{}).(notes.Principal)
		return principal, ok
	},
	ReportInternalError: func(_ context.Context, err error) {
		log.Printf("graphql internal error: %v", err)
	},
	WebSocketInit: func(ctx context.Context, payload json.RawMessage) (context.Context, error) {
		var init struct {
			Token string `json:"token"`
		}
		if err := json.Unmarshal(payload, &init); err != nil {
			return nil, err
		}
		principal, expiresAt, err := verifyToken(ctx, init.Token)
		if err != nil {
			return nil, err
		}
		ctx, cancel := context.WithDeadline(context.WithValue(ctx, principalKey{}, principal), expiresAt)
		context.AfterFunc(ctx, cancel)
		return ctx, nil
	},
})
if err != nil {
	return err
}
defer server.Shutdown(ctx)
http.Handle("/graphql", authenticate(server.Handler()))
```

`ReportInternalError` is required: without it `GraphQL` fails with
"GraphQL generated executor requires caller factory and trusted error
reporter" (verified). `GraphQLConfig` also has `Limits`, `Introspection` (off
by default) and `SubscriptionRecheck`; `server.SDL()` returns the schema.
Queries, mutations and subscription roots run through the same policies.
Subscriptions use `graphql-transport-ws` on a WebSocket upgrade, or graphql-sse
(distinct connections) on a `POST` whose `Accept` prefers `text/event-stream`.

`WebSocketInit` receives the `connection_init` payload without the `golem`
key (the TypeScript client sends its `connectionParams` there). On SSE the
principal comes from the request context, so an HTTP middleware that
authenticates and sets the deadline covers both HTTP and SSE:

```go
func authenticate(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		principal, expiresAt, err := verifyToken(r.Context(), strings.TrimPrefix(r.Header.Get("Authorization"), "Bearer "))
		if err != nil {
			http.Error(w, "invalid principal", http.StatusUnauthorized)
			return
		}
		ctx := context.WithValue(r.Context(), principalKey{}, principal)
		if expiresAt.IsZero() {
			ctx = golem.WithoutCredentialExpiry(ctx)
		} else {
			var cancel context.CancelFunc
			ctx, cancel = context.WithDeadline(ctx, expiresAt)
			defer cancel()
		}
		next.ServeHTTP(w, r.WithContext(ctx))
	})
}
```

### The live handshake (go/v0.8.1)

A subscription is served only to a client that declares the `golem` block
`{"protocol": 1, "contract": "<hex>"}`. `contract` is the lowercase hex of
the server's contract fingerprint, which the generated manifest carries.

- **WebSocket**: in `connection_init.payload.golem`. golem removes the key
  before `WebSocketInit` sees the payload. A `subscribe` message must not carry
  `extensions`.
- **SSE**: in the request's `extensions.golem`.
- **Plain HTTP**: optional; checked when present.

| Mismatch | WebSocket | HTTP and SSE |
|---|---|---|
| protocol (absent, malformed, unknown) | close `4426`, reason `golem:protocol` | `GOLEM_PROTOCOL_MISMATCH` |
| contract (client generated from another schema) | close `4426`, reason `golem:contract` | `GOLEM_CONTRACT_MISMATCH` |

**The ack.** Once a subscription is registered the server sends exactly one
`next` frame before any event:
`{"data":null,"extensions":{"golem":{"live":true}}}`. A refused subscription
gets no ack. For a consistent view: subscribe, wait for the ack, then fetch. A
commit after the ack arrives as an event; one before it is in the fetch.

### The socket deadline (go/v0.8.1)

A live socket closes at a deadline and the reconnect resolves the principal
again; that is how revocation reaches an open socket. The deadline comes from
the principal's context (the context `WebSocketInit` returns, or the SSE
request context):

1. The context has a deadline: that is the credential expiry.
2. No deadline, the context is marked with `golem.WithoutCredentialExpiry`, and
   `EventLimits.RevalidateEvery` is set: open time plus `RevalidateEvery`. For
   API keys.
3. Otherwise the live handshake is refused with
   `GOLEM_PRINCIPAL_DEADLINE_REQUIRED` (WebSocket close `4426`, reason
   `golem:GOLEM_PRINCIPAL_DEADLINE_REQUIRED`; SSE status 400). HTTP queries and
   mutations are never refused for this.

At the deadline the server closes the WebSocket with **`4401`**, with no error
frame first (go/v0.8.2); an SSE stream ends. The client reconnects with fresh
credentials and refetches after the acks. `golem.HasNoCredentialExpiry(ctx)`
reads the marker. golem reads the marker only from the Go context, never from
a client; do not mark a principal that has an expiry.

### The commit report (go/v0.8.1)

A GraphQL response with errors whose operation committed at least one write
carries `{"extensions": {"golem": {"commit": "PARTIAL"}}}`; one whose `COMMIT`
failed without saying whether it applied carries `"UNKNOWN"` (which wins).
Responses without errors, and failures that committed nothing, carry no
extension. A custom mutation error with `committed: true` always comes with
`PARTIAL`. **Do not retry a document that carries the extension**; read back
after `UNKNOWN`. Two mutation roots in one document are two transactions; use
a custom mutation with `caller.Transaction` for atomicity.

### Errors over GraphQL

A `golem.Error` becomes a GraphQL error with `extensions.code` and, where they
apply, `reason`, `limit`, `max`; anything else goes to `ReportInternalError`
as `INTERNAL_SERVER_ERROR`. Validation, limit and binding errors are typed
(`GRAPHQL_VALIDATION_FAILED` with `rule` and `locations`,
`QUERY_LIMIT_EXCEEDED`, `INPUT_LIMIT_EXCEEDED`, `BAD_USER_INPUT` with
`argument`) and never repeat request text.

## 16. The client manifest

`golem generate` writes `zz_golem_client.gen.ts` beside the SDL in every
GraphQL-mode application (not in kernel mode). It is listed in
`.golem/generated-manifest.json`, so `golem check` fails when it is edited or
stale. **Regenerate it after every schema change and ship it to the front
end; never edit it.** It exports `golemClientManifest` (`as const`) and the
type `GolemClientManifest`. Excerpt from the verified example:

```ts
export const golemClientManifest = {
  "contract": "3fce3fc93fd5a8b8ceaff554095225a183ceca0f47dc7584e546a29a5da5ede5",
  "models": {
    "Note": {
      "primaryKey": ["id"],
      "cursorSelector": "ID",
      "uniqueInput": "NoteWhereUniqueInput",
      "events": "noteEvents",
      "relations": {
        "author": { "target": "Author", "list": false, "nullable": true, "inverse": "notes" },
        "comments": { "target": "Comment", "list": true, "nullable": true, "inverse": "note" }
      },
      "computed": {}
    }
  },
  "roots": {
    "deleteNote": { "kind": "generated", "models": ["Note"], "shape": "deletedRow", "nullable": false },
    "drafts": { "kind": "opaque", "models": ["Note"], "shape": "rows", "nullable": false },
    "setPublished": { "kind": "opaque", "models": ["Note"], "shape": "row", "nullable": false },
    "updateManyNotes": { "kind": "generated", "models": ["Note"], "shape": "updateMany", "nullable": false }
  }

```

- `contract`: the fingerprint a client sends in the `golem` block.
- Per model: `primaryKey`, `cursorSelector`, `uniqueInput` (go/v0.8.2; the
  unique input's GraphQL name, `null` without a list or single-row root),
  `events` (the subscription root or `null`), `relations` (`target`, `list`,
  `nullable` (go/v0.8.2), `inverse` or `null`), and `computed` (the models a
  computed field's result holds).
- Per root: `kind` (`generated` or `opaque` for custom, semantic and full-text

  `relationGroupBy` also lists the models it groups by since go/v0.8.3),
  `shape` (go/v0.8.2: `rows`, `row`, `deletedRow`, `aggregate`, `groupBy`,
  `updateMany`, `deleteMany`, `value`) and `nullable` (go/v0.8.2).
- `internal` fields are absent (verified).

## 17. The TypeScript and React client (0.2.1)

Two packages: `@eleven-am/golem-client` (framework-free core on TanStack Query
core) and `@eleven-am/golem-react` (provider and hooks). Server: go/v0.8.3 or
later. Peers: `@tanstack/query-core` ^5, `graphql` ^16, `graphql-ws` ^6 (core);
`@eleven-am/golem-client` ^0.2.1, `@tanstack/react-query` ^5, `react` >=18,
`gql.tada` ^1.8 (React).

### Setup

```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { GolemClient } from '@eleven-am/golem-client'
import { GolemProvider } from '@eleven-am/golem-react'
import { golemClientManifest } from './zz_golem_client.gen'

export const queryClient = new QueryClient()

export const golem = new GolemClient({
  queryClient,
  url: 'https://api.example.com/graphql',
  manifest: golemClientManifest,
  credentials: () => ({
    headers: { authorization: `Bearer ${session.token()}` },
    connectionParams: { token: session.token() },
  }),
})

export function Root() {
  return (
    <QueryClientProvider client={queryClient}>
      <GolemProvider client={golem}>
        <App />
      </GolemProvider>
    </QueryClientProvider>
  )
}
```

- `credentials` is called for every request and every connection, including
  the reconnect after a `4401`; return the current token each time.
  `headers` go on HTTP requests, `connectionParams` into `connection_init`.
- Optional: `createSocket` (a WebSocket factory, for Node) and `fetch`.
- One `GolemClient` per `QueryClient` (a second throws
  `GolemConfigurationError`); `golem.dispose()` releases it.
- `GolemProvider` must sit inside the `QueryClientProvider` of
  `golem.queryClient`, renders its children once live sync runs, and renders
  nothing on the server. Without React: `const stop = golem.live.start()`, then
  `golem.queryOptions(doc, vars)`, `infiniteQueryOptions`,
  `staticQueryOptions` and `golem.mutate(doc, vars, opts)`.

### Hooks

Every hook takes a GraphQL document, as a string (data is `unknown`) or a
gql.tada typed document. A document holds exactly one operation
(`GolemMultipleOperationsError`).

| Hook | Does |
|---|---|
| `useGolemQuery(doc, vars?, opts?)` | a live `useQuery`; its streams are open while mounted |
| `useGolemInfiniteQuery(doc, vars?, opts?)` | a live paged list. Give `take` a defaulted variable (`$take: Int = 20`) or a literal; never write `cursor` or `skip` (`GolemDocumentError`). `hasNextPage` is true while the last page was full |
| `useGolemMutation(doc, opts?)` | `useMutation` over HTTP. The result is never written into the cache; queries over the models it touches are invalidated. `{ keepalive: true }` sends it with `fetch(..., { keepalive: true })` |
| `useGolemStatus(doc, vars?, { infinite? })` | the live status of one query, or `undefined` before it exists |
| `useGolemConnection()` | the client-wide connection status: `idle`, `connecting`, `open`, `reconnecting`, or a fatal close (`unauthenticated`, `forbidden`, `invalid`, `protocol-mismatch`, `contract-mismatch`, `deadline-required`). Since 0.2.1 |
| `useGolemStaticQuery(doc, vars?, opts?)` | fetched once, never refreshed; for documents that cannot be live |

**Live counts.** Aggregates, `groupBy`, `relationGroupBy` and custom roots
whose result holds model rows are live through `useGolemQuery`: any event on a
model they come from refetches the whole document (coalesced); they are never
patched. Put counts in their own query. A document that reaches a model
without `Subscriptions`, or a custom root with no model rows, throws
`GolemNotLiveError`; use `useGolemStaticQuery`.

**Keepalive.** For a last mutation on `pagehide`:
`useGolemMutation(END_SESSION, { keepalive: true })`, or
`golem.mutate(doc, vars, { keepalive: true })`. Treat it as possibly
committed. Bodies over 64 KiB throw `GolemKeepaliveTooLargeError` before
sending.

### Status

| `useGolemStatus(...).state` | Meaning |
|---|---|
| `CONNECTING` | subscriptions opening; the first fetch waits for their acks |
| `LIVE` | every stream acknowledged |
| `RECOVERING` | a stream or the socket was lost; reopening, then one refetch |
| `LIMIT` | the connection's subscription cap was reached; fetched but not live |
| `FORBIDDEN` | access lost; refetches once, does not resubscribe |
| `NOT_FOUND` | a row in a single-row slot left the result; refetches |
| `FAILED` | a stream failed for good (`error` holds the cause) |

The connection state is separate: `golem.transport.status` (`idle`,
`connecting`, `open`, `reconnecting`, `unauthenticated`, `forbidden`,
`invalid`, `protocol-mismatch`, `contract-mismatch`, `deadline-required`) and
`golem.transport.onStatus(listener)`; wrap them in `useSyncExternalStore`.

### Streams, patches and refetches

The client opens one subscription per (model, filter) pair in a document and
adds `_version`, `__typename` and the primary key to every selection of a
model with events. The server filters events; the client never does.

- **Patched in place:** `UPDATED` on a plain stream only: a top-level list or
  single-row root, arguments limited to `where` (or the unique selector), no
  `orderBy`, `distinct`, `take`, `skip` or cursor, scalar fields only.
- **Removed at once, then refetched:** `DELETED` and `EXITED`.
- **Refetched (coalesced):** `CREATED`; every other `UPDATED` (ordered or
  windowed lists, relations, custom roots); every event on aggregates and
  group-by; a response older than the cached `_version`.

### Client errors

Server errors are `GolemError` (`code`, `path`, `extensions`, `retryable`) or
a subclass: `GolemProtocolMismatchError`, `GolemContractMismatchError`
(regenerate the manifest), `GolemDeadlineRequiredError` (a server fix),
`GolemUnauthenticatedError`, `GolemHttpError`, `GolemPartialCommitError` and
`GolemCommitUnknownError` (do not blindly retry). Client-side:
`GolemConfigurationError`, `GolemDocumentError`,
`GolemMultipleOperationsError`, `GolemNotLiveError`, `GolemNotFoundError`,
`GolemProtocolError`, `GolemKeepaliveTooLargeError`.

## 18. Full-text search

Declared in `GolemModel()` (section 4):

```go
golem.FullTextIndex("content",
	golem.FullTextField(Notes.Title, 3),
	golem.FullTextField(Notes.Body, 1),
	golem.TextFolding(golem.FoldDiacritics),
	golem.TextPrefix(2, 3),
)
```

- The name matches `[a-z][a-z0-9_-]{0,62}` and names the methods (`content`
  gives `TextSearchContent`). Fields are local `String` fields with positive
  constant weights; PostgreSQL supports at most four distinct weights.
  `TextPrefix` lengths are 1..32 (SQLite builds prefix indexes; PostgreSQL
  ignores them; prefix queries work on both).
- Storage: SQLite a contentless FTS5 index; PostgreSQL a trigger-maintained
  `tsvector` side table with GIN, requiring UTF-8 and the
  `pg_catalog."und-x-icu"` collation at apply time.
- Forbidden column names: on SQLite `rowid`, or a key column `docid` or
  `_golem_owner_rowid`; on PostgreSQL a primary key column `document`.

```go
results, err := caller.Notes.TextSearchContent(ctx, `invoice "service fee" ref*`, 20)
for _, result := range results {
	row, score := result.Row(), result.Score()
	_, _ = row, score
}
selected, err := caller.Notes.TextSearchContentSelect(ctx, `invoice`, 20,
	golem.Select(notes.Notes.ID, notes.Notes.Title),
	notes.Notes.Published.Eq(true))
```

Methods exist on caller, system and both transaction clients; extra
predicates are AND-ed. GraphQL gets the caller-only root
`textSearchNotesByContent(query:, take:, where:)`.

- **Syntax.** Terms are OR-joined; double quotes form a phrase; a trailing `*`
  on a term or after a closing quote makes the last word a prefix of at least
  two characters (`ref*`, `"service fe"*`). Punctuation separates words. Golem
  quotes every lexeme; raw FTS5 or `tsquery` syntax is never accepted. Limits:
  32 terms, 10,000 bytes, 1,000 results; violations are `BAD_USER_INPUT`.
- **Folding.** `FoldDiacritics` (default) removes marks on both providers
  (`renee` finds `Renée`, verified); `FoldNone` keeps them. Text is NFC and
  case-folded independent of the database locale for indexes generated since
  go/v0.6.0.
- **SQLite writes need a golem connection.** Inserts and updates touching an
  indexed, primary-key or unique column call a golem SQL function that a plain
  `sqlite3` connection lacks. PostgreSQL maintains the index for direct SQL.
- **Ranking.** Default ranking uses no corpus statistics; scores compare only
  within one query. `golem.TextRanking(golem.RankBM25)` uses whole-index
  statistics on SQLite, so unreadable rows can move readable scores: use it
  only for a single-principal corpus. Switching is a reviewed rewrite.
- **Authorization and consistency.** Policy, predicates and the read condition
  of every indexed field apply before ranking. Maintenance is synchronous and
  transactional. Response time still reveals roughly how common a term is
  across the whole index.
- Not provided: stemming, synonyms, snippets, highlighting.

  `embedding.NewSpecification(provider, model, revision, dimensions,
  maxBatch)`) and `Embed(ctx, []embedding.Input) ([]embedding.Vector, error)`;
  map `input.Purpose()` (`PurposeDocument`/`PurposeQuery`) to your vendor's
  modes. Changing the revision marks every row stale.
- **Embedding happens on the queue**: a row is searchable shortly after it is
  written. Candidates are the rows the caller may read; predicates narrow but
  never widen. `SimilarRelated` reads its source through authorization (absent,
  unreadable or masked: `NOT_FOUND`). `take` is 1..1000. Ranking is exact on
  both providers; SQLite uses its bundled `vec1` (`vec1_cos_distance`) since
  go/v0.7.3.
- A vector whose norm is outside [1e-9, 1e9] is refused with
  `SEMANTIC_VECTOR_INVALID` and quarantines only that row. A database still
  holding a pre-v0.5.1 `vec0` table is refused (`SQLITE_VEC_LEGACY_STATE`);
  migrate it with go/v0.7.1 first.
- No reconcile by default: set `QueueConfig.SemanticReconcileInterval` (1 min
  to 24 h) when anything else writes the database, and run
  `application.RefreshSemanticIndexes(ctx)` once after adding an index to a
  model with rows.
- Only `embedding.CodeInvalidInput` quarantines a row; outages and rate limits
  retry without spending an attempt.

## 20. The durable queue

```go
registry := queue.NewRegistry()
welcome, err := queue.Register(registry, queue.Definition[Welcome]{
	Type:        "welcome",
	MaxAttempts: 3,
	Timeout:     5 * time.Second,
	Handle: func(ctx context.Context, job queue.Job[Welcome]) error {
		return sendEmail(ctx, job.Payload)
	},
})
// Open with Queue: &golemruntime.QueueConfig{Registry: registry}

pending, err := welcome.New(Welcome{NoteID: "n1"}, queue.After(30*time.Second), queue.Dedupe("welcome:n1"))
jobID, err := application.Enqueue(ctx, pending) // or tx.Enqueue, or golem.HookEnqueue in a hook
go application.RunQueueWorker(ctx)             // blocks until ctx ends
```

Without `Queue`, every queue entry point refuses with `QUEUE_CONFIG_INVALID`.
Run one worker per application (`QUEUE_WORKER_RUNNING` otherwise); several
processes may each run one, with exclusive claims. Delivery is at least once,
with no ordering; `ExclusiveBy` is the only serialization primitive.

| Definition field | Meaning | Zero means |
|---|---|---|
| `Type` | stable name, `[a-z0-9._-]`, at most 128 bytes | |
| `Handle` | the work; an error schedules a retry | |
| `MaxAttempts` | attempts before `failed` with `attempts_exhausted` | 5 |
| `Timeout` | per attempt; the context is cancelled and the attempt retried | 10 minutes |
| `Backoff` | `queue.Backoff{Base, Cap}`, exponential with full jitter | 5 s, 5 min |
| `MaxConcurrent` | leases of this type held at once by one process | unbounded |
| `ExclusiveBy` | derives a key; jobs sharing it never run concurrently, fleet-wide | |

Fleet-wide budgets are `QueueConfig.Resources` (`queue.Resource{Name,
Concurrency, Costs}`). Options: `queue.After(d)` (at most 24 h);
`queue.Dedupe(key)` (at most 256 bytes) returns the active job's ID while one
with that key is pending or leased.

Handler outcomes: `nil`; an error (retry with backoff); `queue.Terminal(err)`
(fail now, `terminal`); `queue.CompletedWith(code, err)`;
`queue.RetryIn(delay, err)`; `queue.RetryInWithoutAttempt(delay, err)` (never
dead-letters; bound it yourself). A panic retries with `handler_panic`.

**Leases and abandonment.** A claim leases the job for `LeaseDuration` and
renews every third of it; renewals also carry cancel requests. After `Timeout`,
or `ShutdownGrace` at shutdown, the context is cancelled. A handler still
running after `AbandonGrace` is abandoned and the job becomes claimable while
the goroutine runs, so it can run twice concurrently. Honour `ctx.Done()`.

### Worker limits (`QueueConfig.Limits`, start from `queue.DefaultLimits()`)

| Field | Default | Allowed |
|---|---|---|
| `Concurrency` | 4 | |
| `ClaimBatch` | 16 | |
| `LeaseDuration` | 30 s | 1 s..10 min |
| `PollInterval` | 250 ms | at most 24 h |
| `ShutdownGrace` | 15 s | |
| `AbandonGrace` | 5 s | at most 2 min |
| `MaxPayloadBytes` | 1 MiB (also the ceiling) | |
| `RetentionAge` | 30 days | 1 h..10 y |
| `RetentionEvery` | 1 minute | 1 min..24 h, or `queue.RetentionDisabled` |
| `RetentionRows` | 256 per pass | at most 4096 |

Retention is on by default and deletes only terminal rows.

### `OnJobFailed` (go/v0.8.3)

A job type may declare a failure callback. The generated `OnJobFailed` binds a
type to a function that runs **in the same system transaction that marks the
job failed**, so a status write, any `tx.Enqueue` and the `failed` state commit
together:

```go
application, err := notes.Open(ctx, notes.Config[notes.Principal]{
	Database:    database,
	Queue:       &golemruntime.QueueConfig{Registry: registry},
	QueueFailed: []golemruntime.JobFailed[notes.Principal, notes.Actor]{notes.OnJobFailed(notes.ExportJob, notes.MarkExportFailed)},
	ResolvePrincipal: func(_ context.Context, p notes.Principal) (notes.Actor, error) {
		return notes.Actor{UserID: p.UserID, Authenticated: p.Authenticated}, nil
	},
})
```

The callback is `func(ctx, *SystemTx[P], queue.Failure[T]) error`;
`queue.Failure` has `ID`, `Payload`, `Code` (`queue.FailureTerminal`,
`FailureAttemptsExhausted`, `FailurePayloadInvalid`), `Attempt`, `MaxAttempts`,
`EnqueuedAt`.

- A callback error or panic rolls the transaction back; the job is finalized
  again after its lease expires. `QueueOperator().Cancel` stops a stuck one.
- The terminal decision is persisted first, so a failing callback never reruns
  the handler. A crash on the last attempt is finalized by a worker, so its
  callback runs too.
- The deadline is the job's remaining lease. The callback **may run more than
  once**: no external side effects, and guard its writes (match `failure.ID`
  and exclude terminal statuses, section 21). Pass `failure.Code` to clients,
  never error text.
- Every process that registers the type must register the callback, and every
  worker must run go/v0.8.3 or later before you rely on it. Since go/v0.8.4 only
  types with a callback persist a failure intent.

### `ReconfigureQueue` and `QueuePlan`

```go
status, err := application.ReconfigureQueue(ctx, queue.Plan{MaxConcurrent: map[string]int{"export": 1}})
status, err = application.ReconfigureQueue(ctx, queue.Plan{Concurrency: 2})
plan, err := application.QueuePlan()
```

`queue.Plan` has `Concurrency`, `ClaimBatch`, `MaxConcurrent` and
`Capacities` (per resource); `queue.PlanStatus` adds `Generation` and
`AppliedAt`.

- **A plan names only what it changes (go/v0.8.4).** A zero `Concurrency` or
  `ClaimBatch` and any type or resource left out keep their active value.
  Verified: after the two calls above, `QueuePlan()` reported
  `generation=3 concurrency=2 export=1`. (In go/v0.8.3 a plan restated
  everything.) A `MaxConcurrent` of 0 for a named type means uncapped.
- A refused plan (negative value, unknown type or resource, capacity below a
  cost) returns `QUEUE_CONFIG_INVALID` and changes nothing.
- Raising applies on the next claim; lowering lets running jobs finish.
- Works before and while `RunQueueWorker` runs. The plan lives in the process;
  re-apply your saved plan after `Open` on restart.
- Resource capacity is fleet-wide: a raise takes full effect once jobs leased
  under the old capacity end. `Concurrency`, `ClaimBatch` and `MaxConcurrent`
  are per process.
- Costs, resource membership, lease settings and retention need a restart.

### Operating, and `tx.CancelJob`

`application.QueueOperator()` offers `Inspect`, `List`, `ListFailed`,
`CountByState`, `Cancel`, `CancelMany`, `Requeue`, `RequeueFailed`,
`RunRetention` (pages bounded at 256; `Status` never carries the payload).
`Cancel` is immediate for a pending job and cooperative for a leased one
(completion may win).

**`tx.CancelJob(ctx, jobID)`** (go/v0.8.4) on `CallerTx` and `SystemTx`
returns the same `(bool, error)` but commits or rolls back with the
transaction. **Cancel only a job ID read in the same transaction from a row the
caller's policy allowed, never one taken from arguments.** `CancelJob` applies
no policy: verified, a caller cancelled another user's job by ID and got
`true`. Do no slow work after it; on PostgreSQL the job row stays locked until
commit.

**Golem owns `golem_queue`** (`main.golem_queue` on SQLite, `_golem` on
PostgreSQL); any index you add stops startup. Not included: cron, priority.

## 21. The durable-actions pattern

An action that outlives a request (an export, an import) is a status row the
caller watches live, a mutation that records the action and enqueues it in one
transaction, an idempotent handler, `OnJobFailed` for the final failure, and a
cooperative cancel. These functions are in the verified example's
`notes/operations.go`; section 27 runs them and prints
`succeeded`, `failed attempts_exhausted` and `canceled`.

```go
func RequestExport(ctx context.Context, caller *Caller[Principal], args RequestExportArgs) (golem.Row[Export], error) {
	pending, err := ExportJob.New(ExportPayload{ID: args.ID, Fail: args.Fail}, queue.Dedupe("export:"+args.ID))
	if err != nil {
		return golem.Row[Export]{}, err
	}
	var handle golem.Row[Export]
	err = caller.Transaction(ctx, func(tx *CallerTx[Principal]) error {
		jobID, err := tx.Enqueue(ctx, pending)
		if err != nil {
			return err
		}
		existing, err := tx.Exports.FindMany(ctx, Exports.Where(Exports.ID.Eq(args.ID)))
		if err != nil {
			return err
		}
		if len(existing) == 1 {
			if stored, _ := golem.Value(existing[0], Exports.JobID).Get(); stored == string(jobID) {
				handle = existing[0]
				return nil
			}
		}
		handle, err = tx.Exports.Upsert(ctx, Exports.ByID.Value(args.ID),
			Exports.Create(Exports.ID.Create(args.ID), Exports.OwnerID.Create(golem.ActorFrom[Actor](ctx).UserID), Exports.JobID.Create(string(jobID)), Exports.ErrorCode.Create(""), Exports.Result.Create("")),
			Exports.Update(Exports.JobID.Set(string(jobID)), Exports.Status.Set(StatusQueued), Exports.CancelRequested.Set(false), Exports.ErrorCode.Set("")),
			Exports.Select(Exports.ID),
		)
		return err
	}, golem.RetryConflicts(3))
	return handle, err
}
```

```go
func RunExport(ctx context.Context, system System[Principal], payload ExportPayload) error {
	return system.Transaction(ctx, func(tx *SystemTx[Principal]) error {
		current, err := tx.Exports.FindUnique(ctx, Exports.ByID.Value(payload.ID))
		if err != nil {
			return err
		}
		if status, _ := golem.Value(current, Exports.Status).Get(); status != StatusQueued {
			return nil
		}
		if payload.Fail {
			return errors.New("renderer unavailable")
		}
		_, err = tx.Exports.UpdateMany(ctx,
			Exports.ID.Eq(payload.ID).And(Exports.Status.Eq(StatusQueued)),
			Exports.UpdateMany(Exports.Status.Set(StatusSucceeded), Exports.Result.Set("export-"+payload.ID+".zip")),
		)
		return err
	})
}
```

```go
func MarkExportFailed(ctx context.Context, tx *SystemTx[Principal], failure queue.Failure[ExportPayload]) error {
	_, err := tx.Exports.UpdateMany(ctx,
		Exports.ID.Eq(failure.Payload.ID).
			And(Exports.JobID.Eq(string(failure.ID))).
			And(Exports.Status.Ne(StatusSucceeded)).
			And(Exports.Status.Ne(StatusCanceled)),
		Exports.UpdateMany(Exports.Status.Set(StatusFailed), Exports.ErrorCode.Set(string(failure.Code))),
	)
	return err
}
```

```go
func CancelExport(ctx context.Context, caller *Caller[Principal], args CancelExportArgs) (golem.Row[Export], error) {
	var handle golem.Row[Export]
	err := caller.Transaction(ctx, func(tx *CallerTx[Principal]) error {
		observed, err := tx.Exports.FindUnique(ctx, Exports.ByID.Value(args.ID))
		if err != nil {
			return err
		}
		jobID, _ := golem.Value(observed, Exports.JobID).Get()
		if _, err = tx.CancelJob(ctx, queue.JobID(jobID)); err != nil {
			return err
		}
		if _, err = tx.Exports.UpdateMany(ctx,
			Exports.ID.Eq(args.ID).And(Exports.JobID.Eq(jobID)).And(Exports.Status.Eq(StatusQueued)),
			Exports.UpdateMany(Exports.CancelRequested.Set(true), Exports.Status.Set(StatusCanceled)),
		); err != nil {
			return err
		}
		handle, err = tx.Exports.FindUnique(ctx, Exports.ByID.Value(args.ID))
		return err
	}, golem.RetryConflicts(3))
	return handle, err
}
```

The race guards, each one load-bearing:

1. **Record and enqueue together.** `requestExport` enqueues and upserts the
   status row in one `caller.Transaction`; both commit or neither does. The
   owner comes from `golem.ActorFrom` (works in custom mutations), never from
   arguments; the policy makes an upsert over someone else's row an update the
   caller may not make.
2. **Dedupe on the domain key, and compare job IDs.** `queue.Dedupe("export:"+id)`
   coalesces repeated requests while a job is active. In the window where the
   handler committed `succeeded` but the queue has not recorded success, Dedupe
   still returns the old job: the same ID means coalesced (return the row
   untouched); a different ID means a new job, so reset the row to `queued`.
3. **Project the upsert.** `Exports.Select(Exports.ID)` on the upsert is
   required for the mutation to work over GraphQL (rule 3). QUEUE.md omitted it
   before go/v0.8.6, so its `requestExport` failed with
   `COMMITTED_RESULT_UNAVAILABLE` over GraphQL and worked only through `Mutate`.
4. **Handler is idempotent and writes conditionally.** It returns early unless
   the row is `queued`, and its success write is an `UpdateMany` that also
   matches `status = queued`. Under PostgreSQL Read Committed a cancel or
   failure can commit between the read and an unconditional write; the
   predicate makes that write touch zero rows instead of overwriting
   `canceled` (go/v0.8.5). A multi-step handler repeats the check between steps
   and does slow work outside any transaction, writing in a second `SystemTx`.
5. **Failure callback matches the job.** `MarkExportFailed` updates only the
   row whose `job_id` equals `failure.ID` and whose status is neither
   `succeeded` nor `canceled`: lease recovery can fail a job whose handler
   already committed, and a newer request may have replaced the job.
6. **Cancel by the stored job ID, job first.** `cancelExport` reads the row
   through the caller's policy, cancels **that row's** job with `tx.CancelJob`,
   then updates the row only where `job_id` still matches and the status is
   `queued`. Cancelling the job before the status row follows the failure
   callback's lock order (job row, then status row); the reverse deadlocks on
   PostgreSQL. It returns the row read back after the update.
7. **Retry conflicts.** Both mutations pass `golem.RetryConflicts(3)`; a
   conflict, including a serialization failure in `CancelJob` or `Enqueue`, is
   a normal outcome.

For "every new row gets a job" there is no mutation: enqueue from an
`AfterCreate` hook with `golem.HookEnqueue` (section 12). For a stage with
several parents, each parent marks itself done and counts the open parents
under `tx.LockKeys` on the action key; only the one that sees none left
enqueues the child, and the child's `Dedupe` covers the rest. Retry or
reprocess is `requestExport` again: same transaction, same `Dedupe` key. A
server also runs `RunEventPublisher` so clients watching the row see it change.

## 22. Migrations

### Approvals and risk labels

Every operation carries `safe`, `locking`, `rewrite`, `dataLoss` or `manual`.
`migration new` refuses until each operation needing review is approved, and
lists every missing approval with a ready `--approve ... --approve ...` line.
Approval is required for every column type change (including widening
`varchar(200)` to `varchar(300)`, a `rewrite`), every `dataLoss` operation
(dropping a table or column, making a column required, adding a unique key,
primary key or check that rows may violate), a reviewed backfill (`manual`),
and initializing an optimistic-concurrency column. Renames and making a column
optional are `locking` or `safe` and need none.

### Renames and in-place changes

- Renames are recognized by identity: keep `id=` (or the Go name) and change
  `db:` or `table=`; `renameFrom=` claims an unpinned identity once.
- Raising or removing a string limit works on both providers (`rewrite`);
  lowering or adding one is refused.
- SQLite keeps declared column order (a reorder rebuilds the table);
  PostgreSQL appends and ignores physical order for drift.
- A required field without a default cannot be added while SQLite is a
  provider. Only a PostgreSQL-only schema can add one per migration, with
  `migration backfill attach`.
- Temporal columns must match exactly, time zone included; anything else is
  drift (`Open` and `golem doctor`).

### Row versions

The first migration after upgrading to go/v0.8.1+ adds
`golem_version` (`bigint NOT NULL DEFAULT 0`; SQLite `INTEGER NOT NULL
DEFAULT 0`) to every subscribed model and creates the version source first.
No approval. Apply it before starting the new build. The verified example's
`0001_init.sql` on SQLite begins with:

```sql
CREATE TABLE IF NOT EXISTS "golem_row_version" ("value" INTEGER NOT NULL CHECK ("value" >= 0)) STRICT;
INSERT INTO "golem_row_version" ("value") SELECT 0 WHERE NOT EXISTS (SELECT 1 FROM "golem_row_version");
```

### Events written before a regeneration

Each queued fact records the event schema and format that wrote it. After an
upgrade that changes either, the new build cannot decode undelivered facts:
the publisher blocks them (`last_failure_code` `schema-unavailable` or
`format-retired`, visible through `EventOperator().Inspect`), and they can only
be retired with `EventOperator().Retire(ctx, causation)`, losing their events.
**Drain first, on the old build**: stop writes to subscribed models, keep one
old process running `RunEventPublisher`, and wait until this returns 0
(qualify both tables with the system namespace on PostgreSQL):

```sql
SELECT COUNT(DISTINCT o."causation_id") AS undelivered
FROM "_golem_outbox" o
LEFT JOIN "_golem_outbox_delivery" d ON d."causation_id" = o."causation_id"
WHERE d."causation_id" IS NULL OR d."status" IN ('pending', 'leased', 'blocked');
```

Blocked deliveries are not retried on their own: `EventOperator().Resume` or
`Retire` each. Then deploy, and remove old bundles from
`HistoricalEventBundles`.

## 23. SQLite durability profiles

`sqlite.Open` enforces WAL with a verified four-connection pool, and is the
right choice on a local disk. For a database deliberately placed on a network
filesystem:

| Profile | Journal | Connections | Other processes while open | Use when |
|---|---|---|---|---|
| `sqlite.Open` | WAL with `-shm` | 4 | yes (same host) | local disk; single-node NFS 4.1 works since go/v0.7.3 |
| `sqlite.OpenNetworkFilesystem` (go/v0.7.1) | rollback (`DELETE`) | 1 | yes | anything else must open the file while the app runs |
| `sqlite.OpenNetworkFilesystemWAL` (go/v0.7.3) | WAL, `locking_mode=EXCLUSIVE`, no `-shm` | 1 | **no**: other readers, the `sqlite3` CLI and backups fail busy | one process owns the database and wants cheaper commits |

```go
database, err := sqlite.OpenNetworkFilesystem(ctx, sqlite.Config{DataSourceName: "file:/data/application.sqlite"})
```

- All profiles keep `synchronous=FULL`, foreign keys, a 5 s busy timeout and
  immediate transactions; the choice is explicit, never detected.
  `locking_mode` and the other provider-owned pragmas are refused in the DSN.
- A non-empty `<db>-shm` next to the database blocks both network profiles.
  Golem never deletes it. If it is stale: stop every process, confirm
  `BEGIN IMMEDIATE; ROLLBACK;` succeeds in `sqlite3`, then remove it.
- `OpenNetworkFilesystem` converts a WAL-declared database to rollback
  journaling on open (truncating checkpoint, `journal_mode=DELETE`,
  `integrity_check`), keeping rows held only in `-wal`. The integrity check
  reads the whole file: allow minutes in startup probes. When several processes
  open at once, one converts and the others fail after the busy timeout.
- **Backups:** stop readers and writers, close the handle, call
  `sqlite.CheckpointForBackup`, then copy. Never copy a live database or a
  journal separately.
- None of this makes SQLite distributed: do not run several replicas against
  one file.

## 26. Errors and how to branch on them

Operation errors are `*golem.Error`: `Code`, `Reason`, `Operation`, `Model`,
`Field` (only a field the request named), `Limit`, `LimitMax`, `Message`.
`Error()` is `"CODE: message"`; the message never echoes a value, and the
specific internal reason is only in the `errors.Unwrap` chain, for trusted
logs. `ErrorCode` and `Reason` are errors, so `errors.Is` matches both:

```go
func branch(err error) int {
	switch {
	case errors.Is(err, golem.CodeNotFound):
		return http.StatusNotFound
	case errors.Is(err, golem.CodeConflict):
		return http.StatusConflict
	case errors.Is(err, golem.ReasonNotGranted), errors.Is(err, golem.CodeForbidden):
		return http.StatusForbidden
	case errors.Is(err, golem.CodeUnauthenticated):
		return http.StatusUnauthorized
	case errors.Is(err, golem.CodeLimitExceeded):
		var failure *golem.Error
		if errors.As(err, &failure) && failure.Limit == golem.LimitTouchedRows {
			return http.StatusRequestEntityTooLarge
		}
		return http.StatusUnprocessableEntity
	case errors.Is(err, golem.CodeBadUserInput):
		return http.StatusBadRequest
	}
	return http.StatusInternalServerError
}
```

| Code | Typical cause |
|---|---|
| `BAD_USER_INPUT` | invalid input; reasons `VALUE_TOO_LONG`, `VALUE_PRECISION`, `VALUE_RANGE`, `INVALID_VALUE`; NUL in a string; a `system` field named by a caller; a missing required field; a key write to a missing or unreadable row; an upsert create not matching its target; a bad full-text query |
| `NOT_FOUND` | a unique read or write target that is missing, unreadable, or outside the write rule; `Connect` to an unreadable row; an unreadable similarity source |
| `CONFLICT` | a unique collision (also with unreadable rows), PostgreSQL contention, a serialization failure, a late write that depended on an ended `Within` grant |
| `FORBIDDEN` | reasons `NOT_GRANTED`, `FIELD_NOT_READABLE`, `AUTHORIZATION_UNPROVEN`, `POLICY_INVALID`; also without a reason, such as a `CannotUpdateFields` refusal (verified) |
| `UNAUTHENTICATED` | `ResolvePrincipal` returned an error, or a model's policy could not be built |
| `LIMIT_EXCEEDED` | `Limit` is `touched_rows`, `batch_rows`, `facts`, `outbox_bytes`, `nested_depth`, `statement_parameters`, `statement_size`, `statement_aliases`, `selected_fields`, `depth`, `take`, `fanout`, `transaction_ordinal` or `list_items` |
| `COMMITTED_RESULT_UNAVAILABLE` | a custom mutation committed but its result could not be returned |

Mutation limits are also ceilings: you may lower them, never raise them.
Other packages expose `CodeOf(err) (Code, bool)`: `events` (section 14, plus
`GOLEM_EVENT_CONFIG`, `GOLEM_EVENT_TRANSPORT`, `GOLEM_EVENT_CODEC`,
`GOLEM_EVENT_POISON`, `GOLEM_EVENT_PUBLISHER_RUNNING`,
`GOLEM_EVENT_SOURCE_CLOSED`, `GOLEM_CDC_INVALID`, `GOLEM_CDC_UNAVAILABLE`;
`events.ReasonOf` for the reason), `queue` (`QUEUE_CONFIG_INVALID`,
`QUEUE_JOB_NOT_FOUND`, `QUEUE_PAYLOAD_INVALID`, `QUEUE_STORE_FAILURE`,
`QUEUE_WORKER_RUNNING`), `embedding` (`EMBEDDING_INVALID_INPUT`,
`EMBEDDING_PROVIDER`, `EMBEDDING_UNAVAILABLE`), `provider` (`PROVIDER_OPEN`,
`PROVIDER_CONFIG`, `PROVIDER_CLOSE`, `PROVIDER_MAINTENANCE`). Startup and
tooling failures carry a text prefix: `P1_…` from the compiler, `P3_RUNTIME_DRIFT`,
`P4_RUNTIME_CONFIG`, `P6_RUNTIME_CONFIG`, `P8_RUNTIME_DATABASE` from `Open`.

It exercises an `internal` unique lookup, a transaction whose creates run a
hook that `HookEnqueue`s, created/updated/exited/deleted events with versions,
full-text search, policy-filtered reads, the linking rule, a `Within` grant
through `Mutate`, a custom query over GraphQL, the durable-actions pattern with
`OnJobFailed` and `tx.CancelJob`, partial queue plans, a transaction operation
through `Run`, and cascade events. The same program, with `sqlite.Open`
replaced by `postgresql.Open` against a fresh PostgreSQL 17 database migrated
with `--provider postgresql`, printed identical output.

```go
// cmd/notes/main.go
package main

import (
	"context"
	"errors"
	"fmt"
	"io"
	"log"
	"net/http"
	"net/http/httptest"
	"slices"
	"strings"
	"sync/atomic"
	"time"

	"example.com/notes/notes"
	"github.com/eleven-am/golem/go/events"
	"github.com/eleven-am/golem/go/golem"
	"github.com/eleven-am/golem/go/provider/sqlite"
	"github.com/eleven-am/golem/go/queue"
	golemruntime "github.com/eleven-am/golem/go/runtime"
)

type principalKey struct{}

func check(err error) {
	if err != nil {
		log.Fatal(err)
	}
}

func actions(ctx context.Context, stream golem.EventStream[notes.NoteEvent], n int) string {
	var got []string
	for range n {
		event, err := stream.Recv(ctx)
		if code, ok := events.CodeOf(err); ok && (code == events.CodeSubscriptionResync || code == events.CodeSubscriptionOverflow) {
			log.Fatalf("stream ended with %s: refetch and subscribe again", code)
		}
		check(err)
		if event.Metadata().Version() <= 0 {
			log.Fatalf("event %s carries no version", event.Metadata().Action())
		}
		got = append(got, string(event.Metadata().Action()))
	}
	slices.Sort(got)
	return strings.Join(got, " ")
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 60*time.Second)
	defer cancel()

	database, err := sqlite.Open(ctx, sqlite.Config{DataSourceName: "file:notes.db"})
	check(err)
	defer database.Close()

	var application *notes.App[notes.Principal]
	var welcomed atomic.Int32
	registry := queue.NewRegistry()
	notes.WelcomeJob, err = queue.Register(registry, queue.Definition[notes.Welcome]{
		Type:        "welcome",
		MaxAttempts: 3,
		Timeout:     5 * time.Second,
		Handle: func(ctx context.Context, job queue.Job[notes.Welcome]) error {
			welcomed.Add(1)
			return ctx.Err()
		},
	})
	check(err)
	notes.ExportJob, err = queue.Register(registry, queue.Definition[notes.ExportPayload]{
		Type:        "export",
		MaxAttempts: 2,
		Timeout:     5 * time.Second,
		Backoff:     queue.Backoff{Base: 10 * time.Millisecond, Cap: 50 * time.Millisecond},
		Handle: func(ctx context.Context, job queue.Job[notes.ExportPayload]) error {
			return notes.RunExport(ctx, application.System(), job.Payload)
		},
	})
	check(err)

	transport, err := events.NewMemoryTransport(events.MemoryLimits{Buffer: 128})
	check(err)
	application, err = notes.Open(ctx, notes.Config[notes.Principal]{
		Database:       database,
		Queue:          &golemruntime.QueueConfig{Registry: registry},
		QueueFailed:    []golemruntime.JobFailed[notes.Principal, notes.Actor]{notes.OnJobFailed(notes.ExportJob, notes.MarkExportFailed)},
		EventTransport: transport,
		ReportEventOperator: func(_ context.Context, record events.OperatorAuditRecord) {
			log.Printf("event operator %s: %s", record.Action(), record.Outcome())
		},
		ResolvePrincipal: func(_ context.Context, principal notes.Principal) (notes.Actor, error) {
			return notes.Actor{UserID: principal.UserID, Authenticated: principal.Authenticated}, nil
		},
	})
	check(err)

	go func() {
		if err := application.RunEventPublisher(ctx); err != nil && !errors.Is(err, context.Canceled) && !errors.Is(err, context.DeadlineExceeded) {
			log.Printf("publisher stopped: %v", err)
		}
	}()
	for !application.EventCapabilities().PublisherRunning() {
		time.Sleep(time.Millisecond)
	}

	system := application.System()
	var authorIDs []golem.UUID
	for _, handle := range []string{"ada", "bob"} {
		author, err := system.Authors.Create(ctx,
			notes.Authors.Create(notes.Authors.Handle.Create(handle), notes.Authors.System().KeyHash.Create("hash-"+handle)),
			notes.Authors.Select(notes.Authors.ID),
		)
		check(err)
		id, ok := golem.Value(author, notes.Authors.ID).Get()
		if !ok {
			log.Fatal("create returned no identity")
		}
		authorIDs = append(authorIDs, id)
	}
	byKey, err := system.Authors.FindUnique(ctx, notes.Authors.ByKeyHash.Value("hash-bob"), notes.Authors.Select(notes.Authors.Handle))
	check(err)
	handle, _ := golem.Value(byKey, notes.Authors.Handle).Get()
	fmt.Printf("internal key resolves to %s\n", handle)

	ada, err := application.ForPrincipal(ctx, notes.Principal{UserID: authorIDs[0], Authenticated: true})
	check(err)
	bob, err := application.ForPrincipal(ctx, notes.Principal{UserID: authorIDs[1], Authenticated: true})
	check(err)

	adaStream, err := ada.Notes.Events(ctx, golem.EventSelect[notes.Note](notes.Notes.Title))
	check(err)
	defer adaStream.Close()
	bobStream, err := bob.Notes.Events(ctx)
	check(err)
	defer bobStream.Close()

	var publishedID, draftID golem.UUID
	err = ada.Transaction(ctx, func(tx *notes.CallerTx[notes.Principal]) error {
		for _, note := range []struct {
			title, body string
			published   bool
		}{
			{"Renée's invoice", "service fee for September", true},
			{"Draft plan", "roadmap and staffing", false},
		} {
			created, err := tx.Notes.Create(ctx, notes.Notes.Create(
				notes.Notes.Title.Create(note.title),
				notes.Notes.Body.Create(note.body),
				notes.Notes.Published.Create(note.published),
			), notes.Notes.Select(notes.Notes.ID))
			if err != nil {
				return err
			}
			id, _ := golem.Value(created, notes.Notes.ID).Get()
			if note.published {
				publishedID = id
			} else {
				draftID = id
			}
		}
		return nil
	})
	check(err)
	fmt.Printf("ada events: %s\n", actions(ctx, adaStream, 2))
	fmt.Printf("bob events: %s\n", actions(ctx, bobStream, 1))

	results, err := ada.Notes.TextSearchContent(ctx, `renee "service fe"*`, 10)
	check(err)
	title, _ := golem.Value(results[0].Row(), notes.Notes.Title).Get()
	fmt.Printf("search returned %d: %s\n", len(results), title)

	visible, err := bob.Notes.FindMany(ctx, notes.Notes.Where(golem.All[notes.Note]()))
	check(err)
	fmt.Printf("bob sees %d note(s)\n", len(visible))

	if _, err := bob.Comments.Create(ctx, notes.Comments.Create(
		notes.Comments.Body.Create("nice"),
		notes.Comments.Note.Connect(notes.Notes.ByID.Value(publishedID)),
	)); err != nil {
		log.Fatal(err)
	}
	_, err = bob.Comments.Create(ctx, notes.Comments.Create(
		notes.Comments.Body.Create("nice"),
		notes.Comments.Note.Connect(notes.Notes.ByID.Value(draftID)),
	))
	if errors.Is(err, golem.CodeNotFound) {
		fmt.Println("bob cannot link to ada's draft: NOT_FOUND")
	} else {
		log.Fatalf("linking to an unreadable note: %v", err)
	}

	err = ada.Transaction(ctx, func(tx *notes.CallerTx[notes.Principal]) error {
		title, err := notes.Run(ctx, tx, notes.RetitleNote, notes.RetitleNoteArgs{ID: draftID, Title: "Draft plan v2"})
		fmt.Printf("retitled to %s\n", title)
		return err
	})
	check(err)
	before, err := ada.Notes.FindUnique(ctx, notes.Notes.ByID.Value(publishedID), notes.Notes.Select(notes.Notes.GolemVersion))
	check(err)
	oldVersion, _ := golem.Value(before, notes.Notes.GolemVersion).Get()
	_, err = ada.Notes.Update(ctx, notes.Notes.ByID.Value(publishedID), notes.Notes.Update(notes.Notes.Published.Set(false)))
	var failure *golem.Error
	if errors.As(err, &failure) {
		fmt.Printf("direct unpublish refused: %s\n", failure.Code)
	} else {
		log.Fatalf("direct unpublish: %v", err)
	}
	updated, err := notes.Mutate(ctx, ada, notes.SetPublished, notes.SetPublishedArgs{ID: publishedID, Published: false})
	check(err)
	newVersion, _ := golem.Value(updated, notes.Notes.GolemVersion).Get()
	fmt.Printf("setPublished advanced the version: %t\n", newVersion > oldVersion)
	fmt.Printf("ada events: %s\n", actions(ctx, adaStream, 2))
	fmt.Printf("bob events: %s\n", actions(ctx, bobStream, 1))

	server, err := application.GraphQL(notes.GraphQLConfig[notes.Principal]{
		PrincipalFromContext: func(ctx context.Context) (notes.Principal, bool) {
			principal, ok := ctx.Value(principalKey{}).(notes.Principal)
			return principal, ok
		},
		ReportInternalError: func(_ context.Context, err error) {
			log.Printf("graphql internal error: %v", err)
		},
	})
	check(err)
	defer server.Shutdown(ctx)
	web := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		principal := notes.Principal{UserID: authorIDs[0], Authenticated: true}
		server.Handler().ServeHTTP(w, r.WithContext(context.WithValue(r.Context(), principalKey{}, principal)))
	}))
	defer web.Close()
	response, err := web.Client().Post(web.URL, "application/json", strings.NewReader(`{"query":"{ drafts(limit: 10) { title } }"}`))
	check(err)
	body, _ := io.ReadAll(response.Body)
	response.Body.Close()
	fmt.Printf("graphql drafts: %s\n", strings.TrimSpace(string(body)))

	for _, request := range []notes.RequestExportArgs{{ID: "report"}, {ID: "failing", Fail: true}, {ID: "canceled"}} {
		if _, err := notes.Mutate(ctx, ada, notes.RequestExport, request); err != nil {
			log.Fatal(err)
		}
	}
	cancelled, err := notes.Mutate(ctx, ada, notes.CancelExport, notes.CancelExportArgs{ID: "canceled"})
	check(err)
	returned, _ := golem.Value(cancelled, notes.Exports.Status).Get()
	fmt.Printf("cancelExport returned %s\n", returned)

	if _, err := application.ReconfigureQueue(ctx, queue.Plan{MaxConcurrent: map[string]int{"export": 1}}); err != nil {
		log.Fatal(err)
	}
	if _, err := application.ReconfigureQueue(ctx, queue.Plan{Concurrency: 2}); err != nil {
		log.Fatal(err)
	}
	plan, err := application.QueuePlan()
	check(err)
	fmt.Printf("queue plan generation=%d concurrency=%d export=%d\n", plan.Generation, plan.Concurrency, plan.MaxConcurrent["export"])

	go func() {
		if err := application.RunQueueWorker(ctx); err != nil && !errors.Is(err, context.Canceled) && !errors.Is(err, context.DeadlineExceeded) {
			log.Printf("worker stopped: %v", err)
		}
	}()
	for {
		rows, err := ada.Exports.FindMany(ctx, notes.Exports.Where(notes.Exports.Status.Ne(notes.StatusQueued)))
		check(err)
		if len(rows) == 3 && welcomed.Load() == 2 {
			break
		}
		if ctx.Err() != nil {
			log.Fatalf("stalled: %d of 3 exports finished, %d of 2 welcomes", len(rows), welcomed.Load())
		}
		time.Sleep(20 * time.Millisecond)
	}
	fmt.Printf("welcome jobs run: %d\n", welcomed.Load())
	for _, id := range []string{"report", "failing", "canceled"} {
		row, err := ada.Exports.FindUnique(ctx, notes.Exports.ByID.Value(id))
		check(err)
		status, _ := golem.Value(row, notes.Exports.Status).Get()
		code, _ := golem.Value(row, notes.Exports.ErrorCode).Get()
		fmt.Printf("export=%s status=%s code=%s\n", id, status, code)
	}

	if _, err := ada.Authors.Delete(ctx, notes.Authors.ByID.Value(authorIDs[0])); err != nil {
		log.Fatal(err)
	}
	fmt.Printf("ada events: %s\n", actions(ctx, adaStream, 2))
}
```

  row and her notes went with it.

## 28. Kernel mode: golem without GraphQL

```go
func DefineSchema(schema *golem.Schema) {
	golem.SchemaName(schema, "notes")
	golem.WithoutGraphQL(schema)
	golem.Actor[Actor](schema)
	golem.Model[Note](schema)
	golem.Providers(schema, golem.SQLite)
}
```

`generate` then writes only the model, binding, event and registry files: no
SDL, no `zz_golem_graphql.gen.go`, no `golemgqlgen/`, no client manifest, and
the `App` has no `GraphQL` method; `go mod tidy` drops gqlgen. Callers, the
system client, transactions, hooks, events, the queue, `Mutate` and `Run`
work unchanged. `golem.Query` and `golem.ComputedField` fail with
`P5_GRAPHQL_DISABLED_EXTENSION`. Switching modes is a regeneration, not a
migration.

## 29. Recent changes (go/v0.6.5 to go/v0.8.7)

Read RELEASE-NOTES.md before every upgrade. Upgrade paths that need action:

- **0.6.x → 0.7.0**: drain the outbox on 0.6.x (every event schema changed);
  update; regenerate; fix the few signature breaks (keyed literals for
  `events.Limits`, `Config`, `GraphQLConfig`, `MutationLimits`; function values
  of `Transaction` and `Subscriptions`); review error handling and policy
  purity; handle `RESYNC` everywhere. MIGRATION.md lists each change.

  add `golem.MaxItems` to every custom or computed list, update
  `golem.GraphQLList(type, max)` calls, delete any pending
  `.golem-pending-backfill.json`.
- **0.8.0 → 0.8.1**: drain on 0.8.0 (fact codec V3), regenerate, apply the row
  version migration before starting, rename fields called `GolemVersion` or
  `_version`, add the `golem` block to any hand-written live client, give every
  live principal a deadline, handle `EXITED`.
- **→ 0.8.3**: upgrade every worker before relying on `OnJobFailed`.
